## Install safely
1. Back up / branch your Unity 6.3 URP Project Spark project. Close Unity.
2. Extract the FULL ZIP outside the Unity project.
3. In PowerShell from its root, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\Install_Level118_AAA_AutoLayout.ps1 -UnityProjectPath 'D:\Project_Spark_Master_Project\Project_Spark'
```

4. Open Unity and allow import to finish. Commands under `Tools > Project Spark > Automatic Level Generator > 118`:
   - `3. Validate Sources and Report Blockers`
   - `4. Rebuild URP PBR Materials`
   - `1. Build FULL Level_118_Layout` (saves an isolated scene and prefab)
   - `2. Place assembled VISUAL preview on SELECTED tabletop` (requires existing `Table_top` selection)

**Automatic installer only writes under `Assets/ProjectSpark/Level118/TSX26`, backups changed generated code and documentation, and does not overwrite original source assets. Existing `.meta` files are preserved.** The generator output is under `Assets/ProjectSpark/AutoGeneratedLevels/Level118` and should be backed up/version-controlled before rebuilding.
