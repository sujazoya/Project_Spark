# PROJECT SPARK — LEVEL 121: THE PERCEPTION NEXUS (PNX-29)

## Package contents

The FULL ZIP contains `ProjectSpark_Level121_PNX29/` and `Install_Level121_AAA_AutoLayout.ps1` at its archive root. It includes **336 modular OBJ/MTL and GLB pairs**, exactly **280 individually installable components** and 56 separate board/inspection models, **337_L121_AssembledReference.obj/.mtl/.glb** (complete 3D mainboard; all 280 components + four heatsinks), 40 PBR material families, 160 source texture maps, 40 URP packed textures, exact source manifests, 3 fault plans and a 100-test plan. All artwork is physical-scale, metres, Y-up.

## Installation (Windows / Unity 6.3 URP)

1. **Close Unity** and back up or version-control your existing Project Spark project.
2. Extract the **FULL ZIP to a folder OUTSIDE your Unity project**. Do **not** drag the whole zip into Assets.
3. Open a PowerShell terminal in the extracted folder and run:

   `powershell -ExecutionPolicy Bypass -File ".\Install_Level121_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"`

   Adjust the path only if your Unity project is located elsewhere.
4. Reopen the project in Unity and let all OBJ/MTL/textures import. The 337 GLBs are DCC interchange, not used by the Unity builder (no extra GLB importer required).
5. Use the Unity menu **Tools > Project Spark > Automatic Level Generator > 121** in this order:
   - **3. Validate Sources and Report Blockers**
   - **4. Rebuild URP PBR Materials**
   - **5. Create COMPLETE assembled motherboard (VISUAL ONLY)**
   - **1. Build FULL Level_121_Layout** for the independent bare-gameplay-board scene
   - Select `Table_top`, then **2. Place assembled VISUAL preview on SELECTED tabletop**

   Shortcut: **Tools > Project Spark > Levels > Create Level 121** builds the art-authoring scene.
6. Expected output under `Assets/ProjectSpark/AutoGeneratedLevels/Level121/`:

   - `L121_CompleteMotherboard_VISUAL_ONLY.prefab`
   - `Level_121_Layout.prefab` / `.unity`
   - `L121_SourceBlueprint.asset`
   - `ComponentVisualPrefabs/` and `URP_PBR_Materials/`
   - `L121_Layout_Validation.txt`

## Mainboard only

The `ProjectSpark_Level121_PNX29_MAIN_COMPLETE_MOTHERBOARD.zip` file is a separate 3D interchange kit with the combined OBJ/MTL/GLB and PBR maps. Extract and import the OBJ into Unity; do not expect electrical scripts or a gameplay level from this smaller asset package. Use the FULL package for one-click Unity scene generation.

## Preservation / limitation

The installer modifies **only** `Assets/ProjectSpark/Level121/PNX29/`, preserves `.meta` IDs, verifies files *before* copying, backs up overwritten Level 121 Unity editor/documentation files and refuses to overwrite changed source art. Levels 1–120 are not edited. The generator does not call unverified Project Spark APIs, does not install source components in gameplay and never marks routes/vias complete.

**Important:** This is a realistic-style original *procedural* 3D foundation and visual Unity authoring package. It is NOT a hand-finished commercial AAA art certification. The **368 routes, 140 vias, sensor electrical interfaces and U5/U6 W369 physical pins are unapproved**; all six objectives remain blocked. Unity compilation and Play Mode have **not** been executed. This is not real industrial safety equipment.
