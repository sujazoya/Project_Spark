Play Mode acceptance
1 PASS Native pointer selects the original AM5 socket. Verified isolated keyed seating, DDR4 rejection, cooler cross-clamp, A2/B2 retention and M.2 A heat spreader access. The service verifier awarded assembly while all motherboard supplies were off. Checkpoint reload restored service parts while expiring electrical and POST evidence.
2 PASS Measured loaded standby before enabling the main feeds. EPS A measured 12.000 V / 80.0 mA and EPS B measured 12.000 V / 66.7 mA. Power-good and VCORE stayed off with only one measured EPS feed. Both inputs enabled loaded power-good at 3.300 V / 15.0 mA, CPU core at 1.100 V / 110.0 mA, DDR5 at 1.100 V / 33.3 mA, and I/O at 3.300 V / 27.5 mA.
3 PASS Verified staged CPU, DRAM, VGA and BOOT. Both installed memory channels trained. Graphics lane and boot-drive integrity checks completed before POST ready.
4 PASS Native GPU ×16 with M.2 A alone and with A plus chipset D. Native GPU ×8 with both shared CPU M.2 B/C branches occupied. All four drives passed 12/12 block checks. Rejected a wrong width prediction, an empty socket and powered drive service.
5 PASS Three independently observed faults and isolated repairs. VRM_Q03 stopped at CPU while both EPS inputs and power-good remained valid with VCORE at 0.00 V. DDR5_A2 stopped at DRAM with B2 still trained. M2B_CPU stopped at BOOT with M.2 B reading 6/12 blocks and A reading 12/12. Wrong site, wrong spare, missing inspection and powered service were rejected. Each repair required seven fresh loaded readings, POST and all links.
6 PASS Fan loss under solved CPU load dropped VCORE, soak load and power-good while standby remained live. Cooling restoration required full isolation and an explicit reset. Repeat checks in a single powered session did not earn a second boot. Two separately isolated starts passed fresh measurements, POST and link tests. The final run passed 24/24 thermal samples at 1200 RPM with a 37.7 °C peak and a 34.1 °C recovery reading.

Both thermal traces, the two GPU lane widths and the completed workbench were inspected in the Unity screenshots. The automated test used the real campaign, native selection ray, solver and evaluator. Standalone builds, physical touch input, performance budgets and prior-level gameplay regression remain unverified. Logs/Level128Acceptance.txt records the final run.
