# PROJECT SPARK — LEVEL 105 EXPANSION NEXUS

Original board-only 3D geometry: 128 modular FBXs + 128 matching GLBs and 1 assembled mainboard reference FBX/GLB. Includes 100 individually placeable electronic parts, main 270 x 190 mm ENX-13 PCB, separate 80 x 35 mm ECX-4 card, PCIe-style slot with individually modeled contacts, 8 copper-layer reference assets, inspection/repair features, 16 material families and 2K silk. The ECX-4 card model and all of its component meshes are provided separately; do not install a completed card by default.

## IMPORT
Keep the folder together in Unity Assets. Menu: Tools > Project Spark > Levels > 105 > 1. Build EMPTY ENX-13 Board; then 3. Generate Starter PBR Materials. Y-up; vertices use meters. Check units/UVs/normals/material slots within Unity.

## LIMITATIONS
Detailed procedural art foundation, not hand-authored AAA final meshes or manufacturer-qualified PCIe footprints. The 132 routes and 38 vias are unassigned planning data and CANNOT certify continuity. W133 U12/U13 references are logical design labels requiring final schematic pin reconciliation. Unity import and Play Mode not tested. No room/furniture/physical test instruments included.
