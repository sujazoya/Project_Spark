# Project Spark — Level 126 / EPX-34 — The Eclipse Core

This is a procedural visual-authoring package, not electrically qualified flight hardware or a fully playable AAA level. Source models use metres, Y-up. The assembled GLB can be imported into Blender or a glTF-capable Unity importer; Unity generator uses OBJ/MTL and native URP materials. Existing 48 material families are reused, plus two new power finishes.

## Install
Close Unity, back up the project and extract FULL ZIP outside Assets. Run in extracted directory:
```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level126_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
powershell -ExecutionPolicy Bypass -File ".\Install_Level126_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```
Reopen Unity; Tools > Project Spark > Automatic Level Generator > 126. Run 3 Validate, 4 PBR, 5 complete motherboard, 1 full layout, then select Table_top and run 2 assembled preview. Output: Assets/ProjectSpark/AutoGeneratedLevels/Level126. Physical board 0.640 x 0.500 m; uniform tabletop preview 10.13 x 7.914 m (visual only). The upgrade ZIP requires full Level 126 art already installed. Main motherboard ZIP contains assembled OBJ/MTL/GLB and textures; preserve relative paths. GLB has material factors/UVs (not embedded texture maps). The generator is uncompiled; no Unity or real circuit tests have been run.
