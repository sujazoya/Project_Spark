# Project Spark Level 122 — ANX-30: THE AUTONOMY SENTINEL

## Installation (READ FIRST)

**Package:** Original procedural 3D visual motherboard foundation and Unity authoring scripts, NOT a fully playable/certified game level. The source contains 296 part models, 56 structural models, 384 unverified copper plans, 148 unverified via plans, and unresolved W385 physical pins.

1. Close Unity, commit/back up your Unity project and extract `ProjectSpark_Level122_ANX30_FULL_AAA_Original_VisualKit.zip` **outside** the Unity project root.
2. Open PowerShell in the extracted directory and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level122_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

3. Reopen Unity 6.3 URP and wait for OBJ model import to complete. This kit intentionally contains **OBJ + GLB**, not FBX. Do not delete OBJ `*.mtl` files or rename materials.
4. Menu `Tools > Project Spark > Automatic Level Generator > 122 > 3. Validate Sources and Report Blockers`.
5. Menu `... > 4. Rebuild URP PBR Materials`.
6. Menu `... > 5. Create COMPLETE assembled motherboard (VISUAL ONLY)` to generate a finished visual reference prefab (does not install parts in gameplay).
7. Menu `... > 1. Build FULL Level_122_Layout` to create the empty gameplay-authoring scene, all 296 placement slots, 384 blocked routes, 148 blocked vias and blueprint metadata. Scene and prefab are generated under `Assets/ProjectSpark/AutoGeneratedLevels/Level122/`.
8. Select existing `Table_top`, then menu `... > 2. Place assembled VISUAL preview on SELECTED tabletop`. Approximate preview width **10.13 Unity units**, depth **7.60 units**. The original geometry remains **0.560 × 0.420 m**.

### Known limitations and gates

- No electrical schematic, verified manufacturer footprints, RF pin mapping, sensor data or safety qualification is supplied.
- All 384 copper routes = `UNASSIGNED` net/pads and `certifiable=FALSE`.
- All 148 via tasks = `TBD` spans and `UNASSIGNED` net, `verified=FALSE`.
- W385 physical pins are `UNASSIGNED`; no real safety feedback exists until approved and integrated.
- No `LevelGamePlayManager`, `SparkCircuitSystem`, terminal or existing repair API was inspected for this standalone kit.
- Objective counter must start **0/6**. No demo or assembled artwork may award objectives.
- Unity compilation, Play Mode, shader import, player interaction and older-level regressions are **NOT RUN**, not passed.

### Do not repeat known Level 112/114 source validator issues

- Exact model manifest count is **352**, not an inherited previous-level count.
- Exact `Models_OBJ` count is **353 OBJ** (352 modular + assembled reference), with 353 `.mtl` files.
- Exact `Models_GLB` count is **353 GLB**.
- The `ModelManifest.csv` **`obj`** column contains actual `*.obj` filenames; the exporter never uses `NOT_INCLUDED`.
- Run the in-Unity validator first. If it reports a missing OBJ import, confirm the exact OBJ/MTL assets have imported into the Unity project.

### Packaging notes

The installer only adds or updates `Assets/ProjectSpark/Level122/ANX30`, backs up modified Unity scripts/docs, refuses to overwrite changed original source data or meshes, leaves other levels untouched and does not delete `.meta` GUID files. Test the installer and generated prefabs locally before deploying to production.
