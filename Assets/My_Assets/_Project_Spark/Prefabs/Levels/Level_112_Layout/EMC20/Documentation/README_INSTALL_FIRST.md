# Level 112 — The EMC Gauntlet | EMC-20

**Stage:** Advanced AAA-style procedural 3D art foundation + Unity metadata-only builder. NOT playable/AAA-certified, no actual schematic or electrical integration.

## What is included
190 modular OBJ + GLB pairs, plus one assembled reference OBJ + GLB. 22 original PBR material families reused/adapted from the previously authored Project Spark Level 111 art, with 5 source texture maps per family and 22 Unity-packed metallic/smoothness textures; 152 BOM components, 38 art modules, 208 blocked copper records, 68 blocked via records, W209 logical safety mapping, 100 Unity acceptance tests (NOT_RUN). No FBX files.

## Install
Close Unity and back up the project. Extract this full ZIP outside the Unity project. From PowerShell run:

    powershell -ExecutionPolicy Bypass -File .\Install_Level112_AAA_AutoLayout.ps1 -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"

Use `-DryRun` to inspect before copying. Reopen Unity, let models and textures import, then use Tools > Project Spark > Automatic Level Generator > 112 > 3. Validate Sources and Report Blockers, followed by 112 > 1. Build FULL Level_112_Layout. Select Table_top and use 112 > 2. Place assembled VISUAL preview on SELECTED tabletop.

Generated Unity outputs: `Assets/ProjectSpark/AutoGeneratedLevels/Level112/Level_112_Layout.prefab`, `.unity` and `L112_Layout_Validation.txt`. The installed source root is `Assets/ProjectSpark/Level112/EMC20/`.

Source file objects are original procedural geometry for this design, **not manufacturer-quality fabricated circuit boards**. OBJ+GLB mesh and material handling must be visually verified in your project; no source FBX is included. The electrical task CSV fields are intentionally unresolved. No objectives can be certified from this asset kit.
