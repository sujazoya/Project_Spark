## Install

1. Back up Project Spark, close Unity and extract the FULL ZIP outside your project.
2. Open Windows PowerShell inside its extraction directory and run:

   `powershell -ExecutionPolicy Bypass -File ".\Install_Level119_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"`

3. Reopen Unity 6.3 URP. Run menu `Tools/Project Spark/Automatic Level Generator/119/3. Validate Sources and Report Blockers`.
4. Run `119/4. Rebuild URP PBR Materials` then `119/1. Build FULL Level_119_Layout`.
5. To see a separate assembled visual-only tabletop illustration, select your existing `Table_top` with a Renderer and run `119/2. Place assembled VISUAL preview on SELECTED tabletop`.
6. Generated scene/prefab expected at `Assets/ProjectSpark/AutoGeneratedLevels/Level119/`. The source package has editor C#, not precompiled Unity scenes.

## Source-path and migration safeguards

Installer targets only `Assets/ProjectSpark/Level119/MCX27`. It verifies full-file counts and paths before copying. Existing changed original assets cause **preflight abort** (no source overwrite). Changed scripts/docs are backed up into a dated backup folder before overwrite; Unity `.meta` files are not copied or deleted. Generator-only upgrade requires an installed full Level 119 source.

## Important

This source is an **art foundation and Unity editor authoring shell**. It does not integrate with actual `SparkCircuitSystem` and `LevelGamePlayManager` yet. The safety architecture is educational, not machinery-certified. `L119_SourceBlueprint` records are not gameplay authority. All testing requires your real project.
