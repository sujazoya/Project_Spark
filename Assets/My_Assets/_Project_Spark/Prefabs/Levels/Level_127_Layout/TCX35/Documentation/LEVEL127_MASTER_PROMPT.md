## Thermal simulation contract
Use a deterministic fixed simulation step and a lumped thermal network. For each node, C dT/dt = P + sum(Gij(Tj − Ti)) − Gsink(Ti − Tsink). Define explicit units: J/K, W, W/K, Celsius or Kelvin temperature differences, seconds. Bound timestep for numerical stability or use exact constant-input single-node solution. Validate finite positive capacities, nonnegative conductances, energy accounting and sample freshness. Model pump flow feedback and radiator states with bounded, measured signals. Demonstration values are illustrative: C=120 J/K, G=2.4 W/K, sink=10 C, initial=25 C, P=90 W; backup loop effective conductance 65% of nominal. Single-node exact steady state is Tsink+P/G; G=0 gives T=T0+Pt/C. The included teaching component only predicts temperature and has no gameplay authority. Target educational operating band 15–65 C, pending authored scenario verification. Set mission-specific pass thresholds and dwell times in validated config; never present them as real flight standards. Run cold start, nominal heat pulse, primary loop isolation, backup takeover and return-to-normal tests. Independent monitoring must remain active on nonessential inhibit. Ensure safe/manual reset behavior, hysteresis, stale sensor rejection, and clear reason codes.
