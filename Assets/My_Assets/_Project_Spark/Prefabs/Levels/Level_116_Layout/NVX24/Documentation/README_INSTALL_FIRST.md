# Project Spark — Level 116 / The Data Phoenix (NVX-24)

## Deliverable status
A new, procedural, AAA-*style* board-only visual-authoring kit with native Unity OBJ imports, GLB alternatives, PBR source maps, an Editor scene/prefab generator, source validators, and design/QA documentation. **NOT A FULLY PLAYABLE OR AAA ART-CERTIFIED LEVEL.** Real Unity compiler, camera rendering, and Play Mode have not been run here. Component footprints and copper/net connectivity await schematic approval.

## Source facts
- PCB 440 × 310 mm, 24 copper layer ART references.
- 256 original modular OBJ meshes + 256 matching GLB meshes.
- 208 uninstalled component positions and source visual prefab definitions, W289 is ONE of these 208.
- 48 extra board/repair art meshes; assembled OBJ+GLB model 257 is separate and non-gameplay.
- 30 material families, 150 source texture maps (base/metal/rough/normal/AO), 30 packed URP masks.
- 288 UNASSIGNED selected routing records (W001–W288), 100 via records (V001–V100), and W289 independent jumper **OPEN**.
- 3 educational fault plans and 6 planned objectives, all unverified and 0/6 initially.

## Install — full kit
1. Back up the Unity project and close Unity.
2. Extract `ProjectSpark_Level116_NVX24_FULL_AAA_Original_VisualKit.zip` to a folder OUTSIDE Unity's `Assets`.
3. Open PowerShell in the extracted folder and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level116_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Reopen Unity 6.3 URP. Wait for source and model assets to finish importing.
5. Use the menus:
  - Tools > Project Spark > Automatic Level Generator > 116 > 3. Validate Sources and Report Blockers
  - ... > 116 > 4. Rebuild URP PBR Materials
  - ... > 116 > 1. Build FULL Level_116_Layout
  - Select your existing Table_top object and run ... > 116 > 2. Place assembled VISUAL preview on SELECTED tabletop
  - Tools > Project Spark > Levels > Create Level 116 runs the visual-layout builder too.

## Install — upgrade-only
The upgrade-only ZIP requires the complete Level 116 source to be installed already. Extract and run the embedded installer. It copies only revised Level 116 Unity scripts and Documentation; it does NOT create a second source/Data folder.

## Existing tabletop
Your `Table_top` is 15.79 × 8.54 Unity units. Uniform assembled preview uses `min(10.13 / .440, 7.4 / .310)` = about 23.02 scale -> 10.13 × 7.14 Unity units. **This is a VISUAL ONLY preview**. The real game source and future solver must remain 0.440 × 0.310 m.

## Hard blockers
1. 288 routes have no real source pads, destination pads or nets.
2. 100 vias have no approved layer spans, net IDs, or plating/DRC data.
3. 208 source component footprints are NOT approved pin/ball maps.
4. W289 U31 trusted-storage-ready monitor to U30 independent supervisor is a logical intent, not approved physical pins.
5. NAND device organization, timing, ECC code parameters and actual PLP capacitor electrical specs are design-stage.
6. Project Spark electrical solver/selection/shop/tool APIs have not been inspected in this isolated kit.

Never award an objective because a preview mesh, demo calculation, click effect or placeholder flag exists. A 100-case acceptance checklist is included, all NOT_RUN. No Play Mode evidence or actual Unity compiler logs exist.

## Asset import / model path troubleshooting
The source path is exactly `Assets/ProjectSpark/Level116/NVX24`. ModelManifest.csv has the `obj` and `glb` columns and no `NOT_INCLUDED` entries. The validator checks 256 OBJ+GLB pairs, the original source 208 inventory targets and 30 material families. If the asset root is duplicated elsewhere, remove the duplicate after backing it up; Unity builder refuses ambiguous roots.

The installer does not modify preexisting Levels 1–115 or the Universal Generator V2. Existing Level 116 `.meta` files are preserved. Replaced Level 116 scripts are backed up outside `Assets`.
