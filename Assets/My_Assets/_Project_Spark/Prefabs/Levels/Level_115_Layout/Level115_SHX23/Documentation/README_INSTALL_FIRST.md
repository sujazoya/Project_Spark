# PROJECT SPARK — LEVEL 115 / SHX-23 THE SECURE ENCLAVE

## Installation and truthful implementation status

This is a **complete procedural visual-source and level-authoring kit**, NOT a final playable security-certified simulation. It contains a new board, 196 independent component meshes, 44 non-installable board/reference meshes, 22 layer-visualization meshes, a separate completed reference, URP PBR maps, Unity Editor builder, blocked route/via planning records and a non-authoritative educational SHA-256 digest demo.

**Source:** 240 modular OBJ/MTL + 240 matching GLB. Separate 241st assembled OBJ/GLB. 28 PBR material families with BaseColor/Normal/AO/Metallic/Roughness and URP metallic/smoothness maps. All geometry is in metres, with Unity Y-up and board X=0.420 m, Z=0.300 m.

**Initial gameplay-authoring state:** 0/196 installed, 0/272 copper routes, 0/92 vias, W273 OPEN, 0/6 objectives, secure boot UNTRUSTED. The 272 routes and 92 vias lack an approved pin-net design; `UNASSIGNED` and `TBD` must not be changed without reviewed engineering data. U7 and U8 are conceptual monitor/supervisor owners but their physical W273 pins are unknown.

### Install with PowerShell (Windows)

1. Close Unity and back up the Project Spark project.
2. Extract the full ZIP **outside `Assets`**. Keep `Install_Level115_AAA_AutoLayout.ps1` next to the `Level115_SHX23` folder.
3. Run from the extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level115_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Reopen your Unity 6.3 URP project and wait for OBJ imports and shader compilation.
5. `Tools > Project Spark > Automatic Level Generator > 115 > 3. Validate Sources and Report Blockers`
6. `115 > 4. Rebuild URP PBR Materials`
7. `115 > 1. Build FULL Level_115_Layout` (or `Tools > Project Spark > Levels > Create Level 115`).
8. Select existing `Table_top`, then `115 > 2. Place assembled VISUAL preview on SELECTED tabletop`.

**Generated folder:** `Assets/ProjectSpark/AutoGeneratedLevels/Level115/`

- `Level_115_Layout.prefab`
- `Level_115_Layout.unity`
- `L115_SourceBlueprint.asset`
- `L115_Layout_Validation.txt`
- `ComponentVisualPrefabs/` (196 visual-only prefabs)
- `URP_PBR_Materials/` (28)

The tabletop preview is approximately **10.13 × 7.24** Unity units at uniform visual scale. It is colliders-disabled, has no authority, and does not replace the playable 0.420 × 0.300 metre PCB.

### Important restrictions

- This package does not include an approved physical schematic, pin/ball map or trace/via topology.
- No cryptographic private keys are packaged. The SHA-256 demo is *integrity only* and can neither authenticate a signer nor certify firmware. Its Unity script never awards objectives.
- Unity compilation and Play Mode were **not performed** in this build environment. All 100 acceptance tests start `NOT_RUN`.
- Real objective, shop, wiring, tamper/safety, save and UI connections require inspecting the project source first; no speculative `SparkTerminal` or `LevelGamePlayManager` APIs have been called.
- Never install a duplicate Level 115 source folder, or move the original `Level115_SHX23` asset root under an unrecognized path without updating the source locator.
- The installer does not modify previous Levels 1–114; it preserves existing art/data and backs up modified Level 115 source code outside Assets. Git or an explicit project backup is still recommended.
