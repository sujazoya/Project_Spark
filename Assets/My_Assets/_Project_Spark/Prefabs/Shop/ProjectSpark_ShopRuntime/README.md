# ProjectSpark Shop Runtime — Unity 6

## Purpose
Connects the previously generated ProjectSparkShopPanel to **the existing** SparkEconomyService and SparkEconomyCatalog. It does not replace the economy or shop builder.

## Install
1. Copy Runtime/ProjectSparkShopRuntime.cs to Assets/ProjectSpark/UI/.
2. Copy Editor/ProjectSparkShopRuntimeInstaller.cs to Assets/ProjectSpark/Editor/.
3. Keep the previously installed SparkEconomyService.cs and SparkEconomyCatalog.cs. **Do not install duplicate classes.**
4. If not yet done, run Tools > ProjectSpark > UI > Create Complete Shop Panel.
5. Select ProjectSparkShopPanel root in Hierarchy and run Tools > ProjectSpark > UI > Attach Runtime To Selected Shop Panel.
6. Create an EconomyRoot GameObject with SparkEconomyService, assign a SparkEconomyCatalog asset with unique IDs, icons, prefabs and coin prices. Ensure only one service is active.
7. Ensure scene includes EventSystem (Unity UI button interaction) and TextMeshPro essentials.
8. Enter Play Mode. From another button, connect the ProjectSparkShopRuntime.Show public function to open the shop (by default it starts hidden).

## Features
- Real wallet balances from service, automatically refreshed on Economy.Changed.
- Generates cards at runtime from the catalog using the first builder card as a visual template.
- Product icons, selection, categories, quantities and coin purchases.
- Quantity purchase uses repeated one-item transactions, which can partially succeed when funds run out; UI reports the partial count.
- Buys add stock to inventory, not directly onto workbench. Use the existing inventory placement UI to spawn purchased prefabs.
- Sample builder cards are disabled in Play Mode and left in the prefab unchanged.

## Current scope/limitations
- Diamond balances display; diamond checkout not added yet.
- Filter/sort toolbar is visual only. Category filtering is functional (based on product name; for robust taxonomy add an explicit category to catalog items later).
- Button styling is generated by the previous shop builder; supply your own sprites for AAA presentation.
- The runtime controller creates cards during Play Mode only; prefab editing remains safe.
- All purchases are local/offline. Do not use this save for real-money transactions.
