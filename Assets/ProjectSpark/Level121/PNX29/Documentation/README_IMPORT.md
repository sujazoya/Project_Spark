# Project Spark — L121 PNX-29 3D source

Main source folder: ProjectSpark_Level121_PNX29. Exported model units are metres, Y-up. There are exactly 336 modular pairs (280 installable + 56 structural/layer) and 1 independently assembled reference pair (337_L121_AssembledReference). This finished 3D board includes all 280 components, four heatsink art structures and other structural details but excludes all 34 optional layer overlays. OBJ/MTL allows Unity native import; GLB is supplied for Blender and other DCC tools. Unity Editor builder uses OBJ, not GLB, so no extra GLTF importer is required. There are exactly 40 PBR map families. The OBJ material file names L121_<family> and the names are compatible with the custom URP material remapper.
