# INSTALL FIRST — PROJECT SPARK LEVEL 114 / THE THERMAL DOMINION

## Source scope

- This is the **complete, original procedural 3D and Unity visual-authoring package**, not an operational, production AAA gameplay level.
- Original models: **224 OBJ + 224 GLB modular** and **one assembled OBJ + GLB reference**.
- **182 component models** including W257; **42 board/diagnostic art pieces**; **20 inspection-art layers**.
- **26 PBR families** in `Textures` (130 maps) + 26 URP packed maps; no FBX models shipped.
- **256 unassigned route tasks**, **88 unassigned vias**, **6 uncompleted objectives**; schematic/physics/gameplay authority NOT CERTIFIABLE.
- The visual-only assembled reference is NOT an installable component or functional electrical board.

## Installation in Windows PowerShell

1. Back up the Unity project, close Unity, and extract the FULL ZIP **outside** Unity `Assets`.
2. From the folder that contains `Install_Level114_AAA_AutoLayout.ps1` and `ProjectSpark_Level114_TDX22`, run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level114_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

For preflight without copying:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level114_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
```

Installer targets only `Assets/ProjectSpark/Level114/TDX22/`, preserves existing original OBJ, GLB, texture files by default and backs up differing generated files to `ProjectSpark_Backups/Level114_<timestamp>` outside Assets. Preserve `.meta` GUIDs. `-ReplaceOriginalArt` explicitly permits backup+replacement of changed source art; use only when intentionally upgrading source art. Extracted upgrade-only kit requires preinstalled original Level 114 models/textures.

## Build in Unity 6.3 URP

1. Open Unity and wait for OBJ/PNG import and C# compile.
2. Run `Tools → Project Spark → Automatic Level Generator → 114 → 3. Validate Sources and Report Blockers`.
3. Run `114 → 4. Rebuild URP Materials`, then `114 → 1. Build FULL Level_114_Layout`.
4. Select your EXISTING `Table_top` GameObject. Run `114 → 2. Place assembled VISUAL preview on SELECTED tabletop` to see the complete board.
5. The gameplay authoring scene is **empty**, as intended. Generated scene and prefab appear in `Assets/ProjectSpark/AutoGeneratedLevels/Level114/`.

### Correct physical/presentation scale

Actual motherboard: X=0.400m, Z=0.280m, 20 reference layers. Showroom visual preview: ~10.13×7.09 Unity units on your existing 15.79×8.54 table. Do **not** connect this visual scale to electrical distances, solder pads, true collisions or heat conduction geometry.

### Unity source content

`Unity/Editor/SparkL114FullLayoutBuilder.cs` — isolated source validation, procedural authoring menus, source-count checks, blocked route/via records, prefab and scene saving, separate tabletop preview.

`Unity/Editor/SparkL114URPMaterialBuilder.cs` — native URP Lit materials, correct normal/AO import, metallic (red) and smoothness (alpha) masks, remapping using exact family IDs.

`Unity/Runtime/SparkL114LayoutRecords.cs` — metadata-only placement slots, blocked tasks, authority integration anchors.

`Unity/Runtime/SparkL114ThermalSandbox.cs` — deterministic **ILLUSTRATIVE** RC thermal demo, never authoritative objectives.

### Schematic blockers

All 256 selected copper tasks have unassigned source/destination pad/net/layer, and all 88 vias have TBD nets and spans. W257's U11→U10 *logical* signal mapping exists, but both physical pins are unverified. These block electrical gameplay certification. The source does not contain actual manufacturer BGA, MOSFET, heatsink mount and sensor calibration data, thermal conductance/airflow tests or actual Unity project class bindings. These have not been invented. The in-ZIP `L114_Master_Unity_Implementation_Prompt.md` is the handoff to Codex for building and certifying those systems in the real project.

### Validation claims

Offline mesh/data/ZIP checks do not prove Unity compiler passes or Play Mode success. You must run Unity and record the console, asset import, Scene view, performance, thermal responses and actual objective evidence. Do not claim AAA-final baked art or 6/6 completion from this import.
