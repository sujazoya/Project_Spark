# Project Spark — Level 108 Full Auto-Layout Upgrade

## Goal
Turn the uploaded `ProjectSpark_Level108_GhostInCircuit_BoardOnly_Realistic_Complete(1).zip` into a Level 108 full hierarchy generated **inside Unity**, compatible with the installed Universal AutoLevelGenerator V2. The generated `Level_108_Layout.prefab` is source-derived art and editor scaffolding, not a functional solved motherboard.

## User-specified workshop dimensions
- Tabletop: **15.79 × 8.54 Unity units** (horizontal X × Z)
- Target Level 108 motherboard display: **10.13 × 7.51 units**
- Centered margins: **2.83 units** on left/right and **0.515 units** on front/back
- Note: 10.13/7.51 target slightly changes aspect ratio compared with design's 300 × 220 mm. Display sizing only; do not change circuit physics.
- The bare-board visual mesh actually measures **285 × 205 mm**, while the completed reference measures **300 × 220 mm**. The generator fits both to the display footprint while mapping component centers according to design 300 × 220 mm. Do not infer physical pad positions from this transform.

## Installation
Back up the Unity project and close Unity. Do not copy the V2 generator C# source a second time.

Extract the COMPLETE package outside Unity and in Windows PowerShell run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level108_AutoLayout.ps1" -UnityProjectPath "D:\Your\UnityProject"
```

Installer discovers your existing V2 generator (including `Assets/My_Assets/_Project_Spark/Scripts/ProjectSpark/AutoLevelGenerator`), imports *missing* Level 108 source assets, installs only 3 uniquely named C# classes, adds normalized CSV/JSON manifests, and creates/updates one recipe without overwriting existing source meshes. Existing replaced files are backed up.

If using the **upgrade-only** ZIP, first import the original Level 108 asset ZIP (it must contain `Data/L108_Models_152.csv`).

After reopening Unity, select:

`Tools > Project Spark > Automatic Level Generator > 108 > 1. Build FULL Level_108_Layout`

Expected generated output:

```
Assets/ProjectSpark/AutoGeneratedLevels/Level108/
  Level_108_Layout.prefab
  Level_108_Layout.unity
  L108_SourceBlueprint.asset
  L108_Layout_Validation.txt
  URP_PBR_Materials/...
```

Then select the **actual tabletop surface** GameObject (not the entire table with legs) and run:

`Tools > Project Spark > Automatic Level Generator > 108 > 2. Place Level 108 on SELECTED tabletop`

## Source schema compatibility
V2's importer requires fields such as `route_id`, `via_id`, `status`, and objectives JSON. The original Level 108 CSVs use `route`, `via`, `certification`, and objectives CSV. This upgrade installs lossless source-derived normalization files under `Data/L108_AutoGen_*`, leaving originals unchanged.

## Blockers and implementation honesty
The uploaded assets are procedural starter meshes (not final hand-sculpted AAA art), and Source L108 has no certified pin-level netlist or simulated physical repair mechanics. This upgrade does not reconstruct manufacturer-accurate pads, simulate electrical signals, certify routes/vias, or make Level 108 fully playable. You must integrate real `LevelGamePlayManager`, existing `SparkCircuitSystem`, actual pad/terminal/placement/shelf tools, POST, evidence notebook, fault-control and safety systems. The game should start with **0/118 parts, 0/156 routes, 0/50 vias, W157 disconnected and 0/6 objectives**.

## Validation limitations
Asset counts, source schema and ZIP integrity are checked offline. Unity compilation and actual placement onto the user’s scene are **not** available here; run tests and verify mesh axes, scale and materials in Unity before treating the layout as final.
