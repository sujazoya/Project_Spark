PROJECT SPARK / LEVEL 63 - CATCH THE FREQUENCY
Modular high-detail procedural model kit (AAA-inspired art, not final artist-authored AAA).

CONTENTS
- Models/: 34 individual FBX 7.4 binary plus Level63_Complete_ArtKit_Showcase.fbx
- GLB/: 34 individual GLB plus assembled showcase GLB
- Previews/: assembled hero render and all-model contact sheet
- Animation_Rigs.csv: pivot names and global authored positions
- Model_Manifest.json: item names, triangle counts, group pivots
- Unity_Optional/SparkLevel63ArtPlacementEditor.cs: ART-ONLY import and placement tool
- Verification_Report.json: file and archive checks

UNITY SETUP
1. Import the Models/ folder into the project's Assets directory.
2. Place the optional editor C# file under an Editor folder.
3. Select the existing Level 63 layout root in the Unity Hierarchy.
4. Run Tools/Project Spark/Levels/63/Place HD Art Under Selected Layout.
5. Confirm common-coordinate art alignment, material import and scaling.
6. Connect actual SparkElectricalComponent/SparkTerminal gameplay and corresponding visual pivots separately.

MATERIALS: Colored geometry regions are embedded; final PBR textures not authored.
COORDINATES: X width, Y up, Z front, unity scaling nominally 1 unit = 1 meter.
ANIMATION: See Animation_Rigs.csv; pivot names are under their respective model roots.
CAUTION: 58 wires and 90 sockets are DESIGN TARGETS ONLY and NOT present as functional wiring in this pack.
The pack does NOT include a playable level, inverter/flywheel physics, network solver, terminal registrations or six objectives.
Do not place both the showcase model and 34 individual models in the same visible scene.
Unity import/Play Mode have not been tested.
