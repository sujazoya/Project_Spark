## Install
1. Back up your Unity Project Spark directory; close Unity.
2. Extract full package into a folder OUTSIDE your Unity project.
3. Run PowerShell in the extracted package folder:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install_Level111_AAA_AutoLayout.ps1 -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
   ```
4. Open Unity 6.3 URP, wait for OBJ/texture/Script compilation.
5. Use **Tools > Project Spark > Automatic Level Generator > 111 > 3. Validate Sources and Report Blockers**.
6. Use **Tools > Project Spark > Automatic Level Generator > 111 > 1. Build FULL Level_111_Layout**.
7. The builder creates under `Assets/ProjectSpark/AutoGeneratedLevels/Level111/`:
   - `Level_111_Layout.prefab`
   - `Level_111_Layout.unity`
   - `L111_Layout_Validation.txt`
   - `ComponentVisualPrefabs/` containing 138 component art references
   - `URP_PBR_Materials/` containing 22 URP Lit materials
8. In your EXISTING workshop scene select `Table_top`. Use **Tools > Project Spark > Automatic Level Generator > 111 > 2. Place assembled VISUAL preview on SELECTED tabletop**. It is tagged **visual-only** and disables colliders. No room, new table, 3D instruments or unrelated environment is created.
9. Physical gameplay board remains **0.330 × 0.240 m**; the separate preview is approximately **10.13 × 7.367 game-table units** and has no gameplay authority. The enlargement must never be used for physical route measurements.

**Additional shortcut:** Tools > Project Spark > Levels > Create Level 111 builds the visual layout and integration placeholders, NOT a ready-to-play electrical level.

## Safety and performance
Fictional educational signals, not real board programming. The `SparkL111SignalIntegritySandbox` provides deterministic tutorial telemetry only. Its `Sample(...)` outputs always carry `sourceApproved=false` and `classification="ILLUSTRATIVE_ONLY_NONCERTIFIABLE"`. They **must not be presented as real measurements** or used in objectives. No per-frame Update needed. The generator does not modify shared Project Spark gameplay classes or Levels 1–110.

## Quality caveats
These are textured, 3D procedural modeling assets suitable for preview/iteration but not a certified, hand-authored AAA production art pass. Additional LODs, custom UV unwraps, macro bakes, verified footprints/lead pitches, runtime VFX, font/label decals, Unity lighting and platform profiling remain. Imported OBJ material slots should be checked visually in Unity; source `g __PSMAT__...` groups provide fallback identities. If a model has no Renderer after import, the builder fails rather than making fake size claims.
