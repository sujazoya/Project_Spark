# Project Spark — Level 104 Memory Matrix (MMX-12)
## AAA-style PBR visual layout / Unity 6.3 URP

**Delivered stage:** source-preserving visual layout, component visual-prefab inventory, material remapping and blocked engineering task registry. **NOT a functional DDR4 level.**

### Package variants

- **Complete**: source FBX/GLB, textures, source data, 121 OBJ fallback models, 32 additional URP mask/AO maps, Unity Editor/Runtime scripts and a safe PowerShell installer.
- **Generator upgrade only**: generated OBJ fallbacks, URP mask/AO maps, Unity scripts, documentation and installer; requires original `Level104_MMX12` source kit already in the Unity project.

### Installation

1. Back up and close Unity.
2. Extract the ZIP outside `Assets`.
3. Open Windows PowerShell in the extracted directory and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level104_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Open Unity 6.3 URP and allow the meshes, textures, C# scripts to import.
5. Run `Tools > Project Spark > Automatic Level Generator > 104 > 3. Validate Source and 3D Models`.
6. Run `104 > 1. Build FULL Level_104_Layout`, or `Tools > Project Spark > Levels > Create Level 104`.
7. For a **visual-only** tabletop preview: select the existing `Table_top` Transform, then choose `104 > 2. Place Level 104 on SELECTED tabletop`.
8. Do **not** use the preview as a gameplay level; use the physical-scale `Level_104_Layout` prefab as the foundation for future approved electrical integration.

### Critical integration blockers

The original 124 copper tasks have `UNASSIGNED` pads/nets, all 34 via tasks have `TBD` layers and `UNASSIGNED` nets. The `W125_Recovery.json` source identifies U11/U12 as monitor and safety supervisor, but neither appears in the supplied 94-component BOM. The package does **not** invent terminals, auto-pass objectives, grant completed copper, or present actual memory timing results.

No actual Unity project repository or `LevelGamePlayManager` source was supplied. Therefore no electrical adapter or real DDR4 simulation can be correctly integrated or certified here.

### Render/geometry notes

The input GLBs are Y-up and in metres. 121 GLB-derived OBJ fallback meshes retain geometry and are provided with planar fallback UVs because the source GLBs have no UV coordinates. The original FBXs remain unchanged. The `MetalRoughAO` source image channels were treated as R=metallic, G=roughness and B=AO: URP metallic/smoothness alpha uses `255 - G`; occlusion uses B. Material slot mapping uses the fallback MTL family identifiers and `__PSMAT__` geometry markers.

Physical-scale board is 0.260 m × 0.185 m. The independent decorative tabletop preview is approximately 10.13 × 7.21 Unity units for a 15.79 × 8.54-unit table; it must not feed PCB electrical length calculations.

### Validation status

Offline package inspections and file integrity checks can pass without proving Unity C# compilation. Unity compilation, actual FBX/OBJ import rendering, URP shader behavior, Play Mode, save/load, circuit dynamics, DDR4 4-lane training, safe W125 recovery and 6/6 objective proof **are all untested** and must be performed in the user's actual Unity project.
