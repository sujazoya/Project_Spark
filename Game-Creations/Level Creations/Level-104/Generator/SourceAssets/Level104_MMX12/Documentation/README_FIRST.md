# PROJECT SPARK — LEVEL 104: MEMORY MATRIX (MMX-12)

## Board-only asset source kit
- 120 modular FBX / GLB models, plus 1 assembled reference FBX / GLB.
- 94 separate installable board components and 26 PCB/layer/repair details.
- Physical PCB 260 × 185 mm, Y-up, world units meters.
- Eight-layer reference meshes for holographic layer inspection.
- BGA MCU and two DDR4 memory devices have individually modeled underside solder-ball contacts.
- 16 starter PBR material families: albedo, metal/roughness/AO reference, and normals; 2K silkscreen.
- Empty board editor builder and starter URP/Standard material generator.

## Important limitations
This is original detailed PROCEDURAL geometry, not artist-finished/manufacturer-certified AAA hardware. FBX export is custom FBX Binary 7400 and requires Unity import verification. BGA contact patterns are illustration geometry, not package-manufacturer ball maps.
The 124 route records and 34 via records are NON-CERTIFIABLE placeholder tasks; no pin-level schematic has yet been approved. W125 logical endpoints U11/U12 require reconciliation with the 94-component BOM. The board cannot legitimately complete six gameplay objectives until that occurs.

## Import
Place the package under Assets/ProjectSpark/Level104. Execute Tools > Project Spark > Levels > 104 > 1. Build EMPTY MMX-12 Board. Then 3. Create PBR Starter Materials. Verify FBX scale and normals in Unity.
No room, workbench, physical inspection instruments or handheld tools are included. Use existing World-Space Virtual PCB Repair UI.
