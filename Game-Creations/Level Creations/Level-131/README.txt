PROJECT SPARK LEVEL 131 — ASRock B760M Steel Legend WiFi
PROCEDURAL GEOMETRY KIT / VISUAL PROTOTYPE

Install: copy Assets into D:\Project_Spark_Master_Project\Project_Spark (merge, do not replace existing Assets).
Unity: Project Spark > Level 131 > Build Workshop (FBX). If Unity rejects the FBX, use Build Workshop (OBJ fallback).
Select the generated root and run Create and Apply URP Materials to Selection. Save scene and apply prefab overrides if desired.
The builder creates a new scene after asking to save modifications. Generated output is under the kit's Generated folder.
The PCB is 244 x 244 mm at physical scale. Builder scales PCB width to 7.51 Unity units, for a 15.79 x 8.54 tabletop. Check component overhang, orientation and clearances in the scene.
Standalone meshes use local component origins. FBX uses centimeters; OBJ fallback uses meters. Positions are approximate and refer to a top-left board coordinate frame. Assembled FBX uses centered coordinates.

Included: separate meshes, assembled FBX, OBJ backups, BOM, placements, material colors, structural validation and editor scripts.
Not included: measured CAD, genuine board layer artwork, accurate electrical routing/netlist, texture scans, underside populated layout, completed simulation or gameplay. Decorative traces and pin geometry are illustrative, not safe electrical references. No claim of AAA visual fidelity or exact clearances. Some components may overlap; review before production. No Blender/Unity importer was available here: structural checks are not a substitute for importing in Unity. The FBX and OBJ axis conventions should be verified visually before gameplay binding.
