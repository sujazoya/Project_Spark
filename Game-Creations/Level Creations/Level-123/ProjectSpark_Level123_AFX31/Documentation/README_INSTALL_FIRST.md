# Project Spark Level 123 — Flight Sovereign (AFX-31)

## What is delivered

- 368 modular original procedural OBJ+MTL and GLB model pairs; one separate 369_L123_AssembledReference OBJ/GLB.
- 312 installable models + 56 structural/inspection pieces, including eight heatsinks and 38 inactive layer references.
- 580 x 440 x 2.6 mm model in metres and Unity Y-up, plus original 3D geometry preview.
- 44 PBR families; 176 source maps (BaseColor, Normal, AO, MetalRoughAO) and 44 URP MetallicSmoothness maps.
- Full-layout prefab/scene authoring generator; component prefab source art; unscored mixer demonstration; separate complete assembled showcase.
- 400 unassigned route tasks, 156 via tasks without approved spans, W401 open, 3 planned faults, 6 planned objectives.

## Installation

Back up the existing project and close Unity. Extract this full ZIP outside Assets. Open PowerShell in the extracted folder and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level123_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

The script validates filenames and counts BEFORE copying, preserves existing Unity .meta GUID files, backs up modified generated scripts/docs and refuses overwriting modified original source art. It writes only to `Assets/ProjectSpark/Level123/AFX31`.

In Unity 6.3 URP run: `Tools/Project Spark/Automatic Level Generator/123/3. Validate Sources and Report Blockers`; `123/4. Rebuild URP PBR Materials`; `123/5. Create COMPLETE assembled motherboard (VISUAL ONLY)`; `123/1. Build FULL Level_123_Layout`. Select `Table_top`, then run `123/2. Place assembled VISUAL preview on SELECTED tabletop`.

Generated output targets: `Assets/ProjectSpark/AutoGeneratedLevels/Level123/Level_123_Layout.unity`, `Level_123_Layout.prefab`, `L123_CompleteMotherboard_VISUAL_ONLY.prefab`, `L123_SourceBlueprint.asset`, `L123_Layout_Validation.txt`, `ComponentVisualPrefabs` and `URP_PBR_Materials`.

## Design / safety limitation

This is a COMPLETE board-only **visual art/Unity authoring kit** and master AAA gameplay specification, NOT compiled or tested fully playable flight electronics. Certification requires project-specific authentic solver, physical pin maps and tested motor/sensor/safety authority. All 400 routes, 156 vias and W401 remain BLOCKED. Objective state remains 0/6, W401 OPEN, and motor power prohibited. No Unity compile or Play Mode tests were run in this environment.
