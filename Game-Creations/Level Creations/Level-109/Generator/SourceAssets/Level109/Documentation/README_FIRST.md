# PROJECT SPARK — LEVEL 109 / TRX-17 THERMAL ENDURANCE
## Real 3D procedural mesh asset kit (not hand-finished AAA art)

Created as a **new Level 109 procedural library** informed by the supplied Level 108 package and Level 109 thermal concept. Contains **160 individual ASCII FBX 7.4 mesh files and 160 matching glTF/GLB files**. Unlike a renamed-only pack, every asset is generated by the Level 109 mesh recipe, with distinct CPU/heatsink, four-phase VRM, DDR4, fan/monitor/safety IC, removable W165 jumper, copper reference geometry and related parts.

### Deliverables
- 124 individually positionable electronic component mesh assets (L109_Components_124.csv)
- 36 board/cooling/structural/reference mesh assets (L109_Models_160.csv)
- Board-only 300 x 220 mm target, local XYZ in **millimeters**, with **Z up** in authoring coordinates
- Matching GLBs with basic colored PBR glTF materials and ASCII FBXs with per-material geometry
- Reference material PNGs (some inherited from supplied Level 108 package), plus generated flat color/metallic/roughness/neutral normal maps
- Top-down placement plan, fault plan, W165 logic and placeholder electrical route/via lists
- Unity Editor visual assembly helper

### Important production limits
This is a **real, editable procedural 3D starting library**, not manufacturer-accurate or movie-quality AAA modeling. Shapes are simplified, and the 256-pixel generated texture maps are flat reference maps. The meshes lack production UV unwraps, texel density validation, true photogrammetric PBR, bevel baking and artistic wear. Prior Level 108 textures are references and are not automatically bound to FBX materials.

**FBX is ASCII 7.4** exported by a custom mesh writer; GLB is the parallel interchange source. FBX import compatibility with your Unity installation has not been verified. If Unity rejects an ASCII FBX, import the matching GLB through a glTF-capable importer or convert in Blender and re-export binary FBX. Verify axes and import scale; FBX metadata declares millimeter units.

**NOT A FUNCTIONING CIRCUIT:** Routes W001–W164 and vias V001–V054 are planning entries without real schematic nets/pin maps/layer spans. W165's logical safety behavior is defined but physical pins are not. 6/6 objectives cannot be completed from art alone. Never mark a component placed solely because its art is present; integrate using Project Spark's authoritative gameplay and electrical systems.

### How to use in Unity
1. Extract inside `Assets/ProjectSpark/Level109/` and allow Unity to index the files.
2. Inspect one FBX and one GLB, confirm orientation and dimensions (PCB should be 300 × 220 mm), and configure material/shader bindings for URP.
3. Run **Tools > Project Spark > Levels > 109 > Build TRX-17 Visual Reference** for an art-only reference hierarchy. This is NOT the playable level or empty board placement logic.
4. For the actual playable scene, keep the PCB and required fixed structural assets, hide finished board reference components, and spawn component meshes only through verified installation actions.
5. Specify a real electrical schematic, thermal transfer network and a W165 fail-safe state machine before using stress test or certification claims.

No physical room, freestanding instruments, workbench or fan objects are included. Heatsinks and PCB-mounted spreaders are part of the board. All test instruments are intended as Unity World-Space Canvas interfaces.
