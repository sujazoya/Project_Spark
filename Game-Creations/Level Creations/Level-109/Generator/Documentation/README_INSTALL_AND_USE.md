# PROJECT SPARK — LEVEL 109 COMPLETE UPDATED FILES (TRX-17)

## This update solves both previous Unity issues

- **Missing source CSVs / safety JSON:** includes all original Level109 source manifests and normalized V2 objectives.
- **Imported empty PCB has no measurable Renderer:** includes 161 `Models_OBJ_Fallback/` models generated from source GLB mesh data, plus an upgraded full-layout builder that resolves prefixed filenames directly. Specifically, `L109_TRX17_EmptyPCB` maps to `125_L109_TRX17_EmptyPCB.obj`.
- **Table_top has no Collider/Renderer:** the placement tool can use a Transform-only tabletop anchor after confirmation; it deliberately does not inherit the anchor's scale.

## Install in your actual project

1. Back up project and **close Unity**.
2. Extract this ZIP **outside** your Unity project's Assets folder.
3. Open PowerShell in that extracted folder and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level109_Complete_Update.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

The installer finds the *one* existing Universal AutoLevelGenerator V2 even if it is in `Assets/My_Assets/_Project_Spark/Scripts/ProjectSpark/AutoLevelGenerator`. It makes backups **outside Assets** under `ProjectSpark_Level109_Backups`. It never overwrites existing generated `Level_109_Layout.prefab` or `Level_109_Layout.unity` automatically, preserves older levels and does not create a second generator copy.

4. Reopen Unity, wait for the `Models_OBJ_Fallback/*.obj` models to import.
5. Inspect `125_L109_TRX17_EmptyPCB.obj` in the Unity model preview (verify a real mesh appears).
6. Click `Tools > Project Spark > Automatic Level Generator > 109 > 1. Build FULL Level_109_Layout`. If a generated prefab already exists, carefully review and accept the overwrite dialog.
7. Select `Table_top` in the workshop Hierarchy and click `109 > 2. Place Level 109 on SELECTED tabletop`. Confirm only if the transform is the actual top-surface center (its Y is the table-top height). This *places* a new instance; check Hierarchy for old duplicates first.
