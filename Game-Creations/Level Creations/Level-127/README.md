# Level 127 — The Thermal Aegis (TCX-35)
Unity 6.3 URP. This is a procedural VISUAL AUTHORING kit, not a completed playable or electrically certified PCB. Reuses/adapts the Level 126 component package primitives, materials and isolated editor builder; the thermal modules, sensors, layout and other structural artwork are newly generated. GLB includes UVs and material factors; separate PBR maps are supplied for URP.

Extract FULL ZIP outside Assets. Back up and close Unity. In Windows PowerShell 5.1 run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level127_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
powershell -ExecutionPolicy Bypass -File ".\Install_Level127_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```
The installer uses `${mode}:` (not `$mode:`). Static review only; execute locally. It refuses modified art/data, backs up modified updateable files, and copies only into Assets/ProjectSpark/Level127/TCX35. Upgrade ZIP requires the full art already installed.

Unity: Tools > Project Spark > Automatic Level Generator > 127. Run 3 Validate Sources, 4 Rebuild URP PBR Materials, 5 Create COMPLETE assembled motherboard (VISUAL ONLY), then 1 Build FULL Level_127_Layout. Select Table_top and invoke 2 Place assembled VISUAL preview on SELECTED tabletop. The physical PCB is 0.660 x 0.520 m, 3.4 mm thick; tabletop scale is min(10.13/.660, 7.98/.520), approximately 10.13 x 7.98 units. The prefab output path is Assets/ProjectSpark/AutoGeneratedLevels/Level127/L127_CompleteMotherboard_VISUAL_ONLY.prefab.
