# Project Spark — Level 96 Sensor Matrix (SMX-4) FULL Auto-Layout Upgrade

## Included

This package contains **all original 63 FBX and 63 GLB models**, original 44-component BOM and source engineering files, **63 triangulated Unity-readable OBJ fallback models** (from the supplied GLB geometry, maintaining model-local coordinates, UVs, normals and material identities), original **14 physically based texture families**, 28 additional URP-packed metallic/smoothness/AO maps, and a dedicated Level 96 generator/editor with source contact, route, via, objective, fault and safety records.

The original FBX/GLB files and textures are preserved unaltered. The converted OBJ files are fallback mesh imports, not artist-made mesh refinements. The generated URP materials reuse original albedo/normal/glTF ORM textures. They are a realistic **production foundation**, not a claim of hand-finished AAA geometry.

## Installation on your computer

1. Back up `D:\Project_Spark_Master_Project\Project_Spark` and close Unity.
2. Extract this ZIP **outside** the Unity `Assets/` directory.
3. Open PowerShell in the extracted directory and run:

   ```powershell
   powershell -ExecutionPolicy Bypass -File ".\Install_Level96_Full_Update.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
   ```

4. The installer uses your **existing** Universal AutoLevelGenerator V2 folder at `Assets/My_Assets/_Project_Spark/Scripts/ProjectSpark/AutoLevelGenerator` when present; otherwise `Assets/ProjectSpark/AutoLevelGenerator` if present. It never installs a second copy of V2. Original art files are preserved if they already exist. Level 96 builder scripts are backed up before replacement.
5. Open Unity 6.3 URP, let models/textures/scripts finish importing. Check Console for C# errors.
6. Use **Tools > Project Spark > Automatic Level Generator > 96 > 1. Build FULL Level_96_Layout**.
7. Inspect `Assets/ProjectSpark/AutoGeneratedLevels/Level96/Level_96_Layout.prefab`.
8. In your workshop scene select `Table_top`, then **96 > 2. Place Level 96 on SELECTED tabletop**. If `Table_top` is Transform-only, the builder asks you to confirm its world position is the tabletop upper-surface center. It does **not** inherit `Table_top` scale.

If Level 96 is already installed from another package, `-OverwriteSource` is an explicit opt-in to replace changed source files after backing them up. Without it, existing source art is never overwritten. For generated prefabs/scenes, Unity asks permission before replacement.

### Source electrical and gameplay limitations

The source provides 187 contact rows with `UNASSIGNED_PENDING_SCHEMATIC`, 58 conceptual route labels, via records without approved nets and W059 only as a logical feedback path from U8 to U9. No approved component pin-level schematic was supplied. The generated layout therefore has **no fabricated conductive topology** or complete objectives. Connect it to the existing Project Spark `SparkCircuitSystem`, component placement/repair systems, sensor model, virtual world-space UI, save system and real `LevelGamePlayManager` only once real project APIs and an approved schematic have been inspected. The source `SparkLevel96VirtualRepairTarget` is a **visual-only** helper; its `visuallyRepaired` state is not an electrical repair.

Unity compilation, importer compatibility, material visual QA, EditMode and Play Mode tests require verification in your own project; offline checks do not establish them.
