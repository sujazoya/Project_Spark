# PROJECT SPARK LEVEL 124 — ORBITAL BASTION (OBX-32)
## Installation — AAA-style visual/authoring foundation

This package contains the actual assembled OBJ + GLB board plus 384 modular OBJ/GLB pairs, 46 PBR families, Unity Editor layout generator, source CSV/JSON manifests, 100 proposed tests and the master gameplay implementation specification.

**Mainboard:** 600 × 460 × 2.8 mm, Y-up, metres. **328 separately installable models**, 56 structural/inspection models (40 layer references, 8 thermal spreaders, 3 shield structures, 2 diagnostic pads, 2 decorative copper references, 1 PCB substrate). Separate assembled `385_L124_AssembledReference` is a visual-only board including all 328 components and the eight thermal spreaders.

1. Back up your Unity 6.3 URP project and close the editor.
2. Extract `ProjectSpark_Level124_OBX32_FULL_AAA_Original_VisualKit.zip` to any working folder outside `Assets`.
3. Open PowerShell there and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level124_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Reopen Unity and allow all OBJ and texture imports to finish. Do not use third-party GLB importer: the layout builder uses native Unity OBJ files; GLB is supplied for portability.
5. Run menu **Tools > Project Spark > Automatic Level Generator > 124 > 3. Validate Sources and Report Blockers**.
6. Run **4. Rebuild URP PBR Materials**.
7. Run **5. Create COMPLETE assembled motherboard (VISUAL ONLY)**. Expected: `Assets/ProjectSpark/AutoGeneratedLevels/Level124/L124_CompleteMotherboard_VISUAL_ONLY.prefab`.
8. Run **1. Build FULL Level_124_Layout**. This creates separate unassembled layout scene/prefab with 328 empty component targets, 416 blocked copper tasks and 164 blocked via tasks.
9. Select your existing workshop `Table_top`, then run **2. Place assembled VISUAL preview on SELECTED tabletop**.

The installer operates only within `Assets/ProjectSpark/Level124/OBX32` and refuses to overwrite modified source art/data; updated generated Unity scripts and docs are backed up. Existing Levels 1–123 are not intentionally edited. Leave all original `.meta` GUIDs in place when applying updates.

### Source status

All 416 copper tasks and 164 via tasks lack certified endpoints/net/layer spans. W417 planning labels U5/U3 are not approved physical pins. The art preview, teaching calculation and editor output cannot award any mission objective. Unity compilation, Play Mode, real spacecraft dynamics, solver integration and full AAA gameplay are **NOT_TESTED** here.
