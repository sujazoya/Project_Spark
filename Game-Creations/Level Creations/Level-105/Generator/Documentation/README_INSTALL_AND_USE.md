## Installation

1. Back up your Unity project and close Unity.
2. Extract the **Complete** ZIP somewhere outside `Assets/`.
3. Open PowerShell in the extracted folder:

   ```powershell
   powershell -ExecutionPolicy Bypass -File ".\Install_Level105_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
   ```

4. Reopen Unity and allow C# and `.obj` import.
5. Generate: **Tools → Project Spark → Automatic Level Generator → 105 → 1. Build FULL Level_105_Layout**.
6. Select `Table_top` and choose **105 → 2. Place Level 105 on SELECTED tabletop**. The placement helper accepts an empty Transform as a tabletop *surface-center anchor* after confirmation. Never parent the generated board under a scaled tabletop.

The 3D model scale is a workshop presentation scale; the electrical solver must use real engineering units.

## Important source limitations

The original art is realistic-style *procedural* geometry, not finished artist-authored photorealism. The PBR texture maps contain modest variation and flat normal maps. This upgrade retains those maps and makes correct URP channel packing; real AAA finishing still requires UV unwrapping, mesh refinement, texture art, import checks and lighting work.

The shipped source `SparkL105MaterialBuilder.cs` contains an invalid backslash character literal. For safety this installer **does not put the original source Editor scripts into the Unity compiler**. They are retained as `.cs.txt` in `Documentation/OriginalEditorReference/` for inspection. The new generator uses a corrected material builder.

The 132 copper tasks, 38 vias, W133 pins and exact solder pads have not been approved. The level can be visually generated, but full playable electrical simulation, PCIe training, 6/6 certification, and `LevelGamePlayManager` hooks must be implemented and tested in the actual Unity project. *No test has been executed in Unity by this package generator.*

## Troubleshooting

- No recipe: locate `Level105_ENX13.recipe.json` under your existing `AutoLevelGenerator/Recipes`. V2 should discover it automatically.
- Empty PCB has no Renderer: confirm `Models_OBJ_Fallback/101_L105_PCB_ENX13_270x190mm.obj` is imported with a MeshRenderer; the builder tries that first.
- Pink materials: make sure URP is active and open generated `URP_PBR_Materials` to inspect URP/Lit textures; original FBX textures are retained.
- Missing card: confirm `110_L105_ECX4_RemovableCard.obj` and six ECX-4 component source files are imported.
- W133 not certifiable: correct until a signed pad/pin schematic is supplied.

Its result is saved to `Assets/ProjectSpark/AutoGeneratedLevels/Level105/L105_Source_Import_Audit.txt`. This is an **import check only**, not gameplay or electrical certification.
