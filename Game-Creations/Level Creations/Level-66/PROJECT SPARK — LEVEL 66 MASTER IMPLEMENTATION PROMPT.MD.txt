# 14. BEARING FAULT FREQUENCIES

Implement optional rolling-element bearing fault-frequency calculations.

Use bearing geometry parameters:

- Number of rolling elements.
- Rolling element diameter.
- Pitch diameter.
- Contact angle.
- Shaft rotational frequency.

## BALL PASS FREQUENCY — OUTER RACE

`BPFO = (n/2) * fr * (1 - (d/D) * cos(theta))`

## BALL PASS FREQUENCY — INNER RACE

`BPFI = (n/2) * fr * (1 + (d/D) * cos(theta))`

## BALL SPIN FREQUENCY

`BSF = (D/(2*d)) * fr * (1 - ((d/D)*cos(theta))^2)`

## FUNDAMENTAL TRAIN FREQUENCY

`FTF = (fr/2) * (1 - (d/D) * cos(theta))`

where:

- `n` = rolling element count.
- `fr` = shaft rotational frequency.
- `d` = rolling element diameter.
- `D` = pitch diameter.
- `theta` = contact angle.

Use appropriate assumptions about rolling contact and slip.

## REQUIRED BEHAVIOR

Fault-frequency components must shift with shaft speed.

Do not hardcode bearing damage to a fixed 80 Hz tone at all RPM values.

Use these expressions as an educational approximation, not a universal exact diagnosis.
