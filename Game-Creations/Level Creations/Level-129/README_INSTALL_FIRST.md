# Project Spark — Level 129: The Silicon Workshop
## MSI PRO H610M-E (DDR5) — FBX HD visual/authoring kit
This is an original procedural recreation based on the public commercial product, not manufacturer CAD. The assembled board is a factory-populated motherboard without aftermarket CPU, memory or SSD. All electrical connectivity and small-part coordinates remain illustrative.

## Asset inventory
- 456 modular FBX 7.4 binary files plus two complete board FBX files (458 FBX total).
- 441 factory components; 9 removable hardware objects; 5 optional service models; one substrate.
- 78,592 assembled triangles, including 1,700 illustrative LGA contact meshes. The contact field is not a verified physical pin map.
- Detailed hierarchy and 18 material-batched meshes. The latter is for showcase only, not per-part repair.
- 19 material families; 57 2048x2048 PNG maps (BaseColor, Normal, MetallicSmoothness). Original front and backside decorative atlas, reused Project Spark material finishes and additional materials. Some normal maps are flat. No manufacturer texture scan.
- GLB backup has UVs and PBR factors; texture PNG files are external. FBX textures are not embedded; use the Unity URP builder.
- mATX PCB: 200 x 236.16 mm (X/Z), assumed 1.6 mm substrate. Rear sockets may extend past PCB edge.

## Install with Windows PowerShell 5.1
Back up your Unity project and close Unity. Extract the FULL ZIP to a folder outside Assets. Open PowerShell there. The directory must contain the installer, SHA256SUMS.csv and Assets.

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level129_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
powershell -ExecutionPolicy Bypass -File ".\Install_Level129_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```
DryRun verifies every source hash and reports proposed changes; writes nothing. Differing existing package files are rejected unless `-ReplaceExisting` is specified. Replacement backs up originals outside Assets, preserves existing .meta files, and touches only Level129 source paths. No other levels are modified. The format string avoids the PowerShell 5.1 `$mode:` bug.
