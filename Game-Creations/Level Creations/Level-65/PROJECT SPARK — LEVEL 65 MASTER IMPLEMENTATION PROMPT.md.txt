# 10. CONVEYOR ENCODER SIMULATION

Use:

`03_L65_ConveyorRotaryEncoder.fbx`

This is one of the most important Level 65 systems.

## REQUIRED PROPERTIES

- Roller radius.
- Encoder pulses per revolution.
- Actual roller angle.
- Pulse count.
- Measured direction.
- Measured belt speed.
- Measured displacement.
- Calibration status.
- Connectivity.
- Measurement validity.
- Timestamp.
- Signal freshness.

## ENCODER DISTANCE EQUATION

For N pulses:

`Distance = (2 * PI * RollerRadius * PulseCount) / PulsesPerRevolution`

## ENCODER SPEED

`MeasuredSpeed = DeltaDistance / DeltaTime`

Use valid sample intervals.

## REQUIRED BEHAVIOR

- Actual belt movement causes roller rotation.
- Roller rotation causes encoder pulses.
- Encoder pulse count determines measured displacement.
- Measured speed responds to pulse rate.
- Missing pulses while motion is expected can trigger a fault.
- Disconnection makes measurement invalid.
- Stale measurements cannot be treated as valid zero speed.

## CALIBRATION

Require:

1. Valid encoder supply.
2. Valid feedback wiring.
3. Correct roller radius.
4. Correct pulse resolution.
5. Correct direction.
6. Stable measurement interval.
7. Valid comparison with known motion.

Do not allow calibration when feedback is missing.

# 18. ROBOT FORWARD AND INVERSE KINEMATICS

Implement a coherent six-axis kinematic system.

## FORWARD KINEMATICS

The tool pose must be derived from the actual joint configuration.

Conceptually:

`ToolTransform = T1(q1) * T2(q2) * T3(q3) * T4(q4) * T5(q5) * T6(q6) * Ttool`

Use valid local axes, offsets and transform order.

## INVERSE KINEMATICS

The motion controller must determine reachable joint configurations for the requested tool pose.

Acceptable approaches include:

- Validated analytic inverse kinematics.
- Iterative damped least-squares solver.
- Constrained iterative IK.
- Verified preconfigured joint poses and interpolated joint-space motion where full IK is impractical.

## REQUIRED SAFEGUARDS

- Joint limits.
- Unreachable target rejection.
- Singular configuration handling.
- Maximum velocity.
- Maximum acceleration.
- Collision avoidance.
- Tool orientation constraints.
- Safe stopping.

## IMPORTANT

If full six-axis IK cannot be implemented reliably, use a documented joint-space pose library and valid continuous trajectories.

Never claim unrestricted six-axis IK when using only fixed predefined movements.
