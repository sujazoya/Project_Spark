# Project Spark — Level 107 PFX-15 Phoenix Protocol
## Full layout + tabletop fit addon for Universal Generator V2

This addon uses the **uploaded Level 107 ZIP** as the geometry/data source and the Level 107 master implementation prompt as the engineering requirements. No fabricated electrical pin maps have been introduced.

### Source inventory
- 144 modular FBX + 144 modular GLB source files, and 1 assembled visual reference FBX + 1 GLB.
- 112 uninstalled component tasks; 32 art/structure references.
- 148 routes, 46 vias; **all NOT_CERTIFIABLE / UNASSIGNED**.
- 3 recoverable faults: F1 SPI CS contact, F2 corrupt primary firmware, F3 recovery pull-up.
- 6 source objectives and removable W149 safety-feedback path.
- 10 nominal copper layers. No validated pin-level board schematic.
- Original procedural bare PCB about **285 x 205 mm**, desired PFX-15 **290 x 210 mm**; the builder measures the imported mesh before fitting to the workshop.

### Workshop fit
- Real tabletop: **15.79 x 8.54 Unity units**.
- Level board display footprint: **10.13 x 7.51 Unity units**, centered.
- Margin each side: **2.83 units**, front/back **0.515 units**.
- A `Table_top` Transform-only anchor is supported. A confirmation dialog assumes its **world position** is the tabletop *surface center*, so verify the Y position. Its Transform scale is ignored, and the generated layout is not parented beneath the table.

### Installation (with your actual project path)
1. Back up the project; close Unity.
2. Extract the **full** package into a temporary folder outside Unity.
3. From PowerShell in that extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level107_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Open Unity and wait for asset import/compilation. The installer adds three **Level-107-only** scripts under the already-installed generator (it never copies a second V2 core).
5. In the Universal Generator V2 select `Level 107 | PFX15 | Phoenix Protocol`, click `Refresh / Rescan Assets`, then **Validate**.
6. Use the specialized menu: `Tools > Project Spark > Automatic Level Generator > 107 > 1. Build FULL Level_107_Layout`. The generic `3. Build Imported` builds a simpler scaffold, not the full prefabricated hierarchy.
7. Select `Table_top` in the Hierarchy and use `107 > 2. Place Level 107 on SELECTED tabletop`. Confirm the tabletop Y surface if it has no Renderer/Collider.

### Main generated hierarchy
`Level_107_Layout` -> board art; 112 uninstalled component slots; physical-pad placeholder; topology placeholder; 148 unqualified routing task objects; 46 unassigned via objects; 10 layer reference objects; service geometry; disabled assembled reference FBX; three faults; six objectives; W149 safety placeholder; SPI/firmware/boot bindings; and virtual instrument/control hooks.

**IMPORTANT**: The source ZIP is a visually detailed but procedurally reused mesh library. The builder does not create true manufacturer pin numbers, physical solder pads, net connectivity, firmware simulation, repair mechanics, or objective authority. Only after schematic approval and connection to your real `LevelGamePlayManager` may the level legitimately award 6/6. The preflight and ZIP checks are offline; Unity compile/Play Mode are not verified here.

### Preserve other levels
Generator class names and menu paths are unique to Level 107. The installer backs up any existing Level 107 addon script before replacing it, and preserves existing model files. Level 108/109 and all earlier scenes are not deliberately changed. Do not edit prefab contents manually if you intend to regenerate them; copy to a new prefab.
