# Project Spark Level 113 — The Redundancy Citadel (RDX-21)

**Provided:** Advanced 3D/URP layout kit and engineering implementation specification. **Not completed:** real electrical simulation, playable objective authority, approved safety pin mappings, Unity compilation or AAA certification.

## Assets
206 original procedural modular OBJ/GLB pairs (166 installable + 40 board/detail) plus one complete OBJ/GLB assembled reference. 380×270mm, 18 layers, 24 PBR families with 120 maps and 24 URP packed masks. 232 copper route placeholders, 76 via placeholders, W233 logical fail-safe jumper. No FBX export is included.

## Installation
1. Back up your Unity project and close Unity.
2. Extract the **complete ZIP** outside the Unity project, keeping `Install_Level113_AAA_AutoLayout.ps1` beside `ProjectSpark_Level113_RDX21` folder.
3. Preview installer changes:

    powershell -ExecutionPolicy Bypass -File ".\Install_Level113_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun

4. Install without `-DryRun` and reopen Unity. Allow OBJ/GLB texture import.
5. Run `Tools > Project Spark > Automatic Level Generator > 113 > 3. Validate Sources and Report Blockers`, then `113 > 1. Build FULL Level_113_Layout`.
6. Select existing `Table_top` and choose `113 > 2. Place assembled VISUAL preview on SELECTED tabletop` for a **separate visual reference only**. The gameplay prefab starts empty.

## Unity artifacts
`Assets/ProjectSpark/AutoGeneratedLevels/Level113/Level_113_Layout.prefab` and `Level_113_Layout.unity`, with source validation report and `ComponentVisualPrefabs/` and `URP_PBR_Materials/` folders. Scene/prefab files are created **in Unity** only.

## Safety caveat
All planned routes/vias remain `SCHEMATIC_REQUIRED`; W233 logical U15/U6 endpoints are not actual package pin numbers. The included synthetic resilience sandbox is a labeled teaching demonstration and cannot grant objectives. Actual Project Spark electrical/VRM/ECC/repair integration needs the project code and approved netlist. Source-only structural checks do not confirm Unity compiler or Play Mode.
