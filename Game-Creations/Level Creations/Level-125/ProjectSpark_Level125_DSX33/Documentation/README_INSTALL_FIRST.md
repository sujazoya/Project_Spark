# Project Spark — Level 125 / DSX-33 — The Signal Horizon

## Install the visual-authoring kit
This is a procedural 3D design foundation for Unity 6.3 URP, not a finished playable or certified spacecraft radio. Contains 400 modular OBJ/GLB pairs, 344 component records, 42 inspection artwork layers, 48 PBR material families (46 reused from Level 124 and 2 RF-specific variants), and one separate combined assembled reference. GLBs carry material factors and UVs; use OBJ/MTL + the provided texture library for full Unity URP material binding.

1. Back up and close Unity. Extract the FULL ZIP outside the project. Keep the installer next to `ProjectSpark_Level125_DSX33`.
2. In PowerShell, run the following dry run first:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level125_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
```

3. If successful, repeat without `-DryRun`. The installer targets only `Assets/ProjectSpark/Level125/DSX33`. Existing identical files are skipped; changed source art/data is not overwritten; updated scripts/docs are backed up outside Assets, and .meta files are retained. The installer itself has not been executed on Windows here.
4. Reopen Unity; let asset imports finish. Use `Tools > Project Spark > Automatic Level Generator > 125` in order: **3. Validate Sources and Report Blockers**, **4. Rebuild URP PBR Materials**, **5. Create COMPLETE assembled motherboard (VISUAL ONLY)**, **1. Build FULL Level_125_Layout**. The last command opens a new authoring scene after prompting to save modified scenes. Select `Table_top` and use **2. Place assembled VISUAL preview on SELECTED tabletop** only for display.
5. Generated assets go under `Assets/ProjectSpark/AutoGeneratedLevels/Level125/`. Display preview scale is about 10.13 × 7.84 Unity units; physical assets use metres, 0.620 × 0.480. Do not use preview transform scales in circuit calculations. The combined board's W433 jumper is visible for showcase; the gameplay record begins OPEN.

### Package alternatives
The MAIN COMPLETE MOTHERBOARD ZIP is a direct visual import, with OBJ/MTL, GLB and texture directories. Keep relative MTL paths intact; GLB import in Unity requires an appropriate importer. The Generator Upgrade Only ZIP contains scripts, tests and documentation only: install the original full kit first. Do not import both full-source copies into Assets; duplicate source roots deliberately fail validation. Do not put separate showcase assets inside a duplicate source root.

### Important blockers
No verified physical netlist, pin map, real RF model, routable stack-up or existing runtime integration supplied. Copper artwork is not electrically connected. All 432 routes, 172 vias and W433 remain unassigned; all objectives begin 0/6. Unity compilation, scene build and Play Mode are NOT_RUN. See the master implementation prompt before integration.
