# Project Spark Level 120 — THE AXIS FORGE / RAX-28

## READ FIRST: complete visual motherboard + empty gameplay board

The complete assembled mainboard is the original standalone 3D model `ProjectSpark_Level120_RAX28/Models_OBJ/321_L120_AssembledReference.obj` plus its matching GLB. It includes all 264 parts and six heatsink art assemblies. **It is not a gameplay-cleared board.**

The separate Unity gameplay scene starts with 0/264 uninstalled parts, 0/352 real routes, 0/132 approved vias, W353 OPEN, safety authority unbound and 0/6 objectives. An assembled art model cannot install parts or create electrical nets.

### Install into the real Unity project

1. Make a backup or branch. Close Unity.
2. Extract the full package outside Unity, preserving `ProjectSpark_Level120_RAX28/` and the `.ps1` installer in the same folder.
3. From that extracted folder run PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level120_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Reopen Unity 6.3 URP, wait for imports. `Models_OBJ` is the Unity-native fallback; GLB requires a glTF importer if you wish to import the original GLBs directly.
5. Run `Tools > Project Spark > Automatic Level Generator > 120 > 3. Validate Sources and Report Blockers`.
6. Run `120 > 4. Rebuild URP PBR Materials`.
7. **To see the entire complete motherboard immediately:** run `120 > 5. Create COMPLETE assembled motherboard (VISUAL ONLY)`. Then look at `Assets/ProjectSpark/AutoGeneratedLevels/Level120/L120_CompleteMotherboard_VISUAL_ONLY.prefab`.
8. To generate the **unassembled gameplay authoring level:** run `120 > 1. Build FULL Level_120_Layout`.
9. To place a visual complete board on the existing lab table: select `Table_top` in Hierarchy and run `120 > 2. Place assembled VISUAL preview on SELECTED tabletop`.

### Output assets

`Assets/ProjectSpark/AutoGeneratedLevels/Level120/` contains:
- `L120_CompleteMotherboard_VISUAL_ONLY.prefab` (the full assembled mainboard)
- `Level_120_Layout.prefab` (empty physical board + 264 installable targets)
- `Level_120_Layout.unity` (independent Unity scene)
- `L120_SourceBlueprint.asset` (source-authoring records; no certified wiring)
- `ComponentVisualPrefabs/` (264 individual uninstalled component prefabs)
- `URP_PBR_Materials/` (38 material families)
- `L120_Layout_Validation.txt`

The board is 520 × 380 × 2.2 mm in physical metres. The optional uniformly scaled showcase is roughly 10.13 × 7.35 Unity units at most, suitable for the existing ~15.79 × 8.54 tabletop if oriented correctly. Do not feed this display scale into the electrical solver.

### Import and fault blockers

Manifest: 320 modular models, 264 BOM, 264 placements, 352 routes, 132 vias, 321 total OBJ and 321 GLB files (assembled reference included). **Never use NOT_INCLUDED as a filename.** All route source/destination/net fields are `UNASSIGNED` and via spans `TBD`; W353 U47/U48 physical pads unassigned. Footprints remain unverified. Therefore the signed schematic, motor specifications, kinematic parameters, actual Unity project integration, C# compile and Play Mode verification are still required before playable certification.

Source file installation refuses to overwrite modified original models/data, and writes backups for changed Unity scripts/documentation while preserving .meta/GUIDs. Other levels are not modified by the installer. If Unity reports an error, share the exact Unity Console output with source path and line number.
