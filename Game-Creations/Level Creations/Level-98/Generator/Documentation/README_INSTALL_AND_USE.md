# Project Spark — Level 98 Transient Shield (PIS-6)
## Full Visual Layout Upgrade / Unity 6.3 URP

This package upgrades the **existing** Project Spark AutoLevelGenerator V2. It builds source-backed **Level_98_Layout.prefab** and scene with authentic original realistic-style meshes, 21 URP PBR material families, installation targets, concept route/via records, a disabled complete-board reference, and scaffolding for existing virtual PCB tools. It **does not** include certified electrical pin mapping or a complete working power-integrity solver. No claim of AAA hand-finished art or Play Mode validation.

### Source inventory

- 74 original modular FBX and 74 original GLB models; one separate assembled FBX+GLB reference.
- 75 additional OBJ+MTL fallbacks made from GLB geometry (source Z-up to Unity Y-up); original geometry and named material groups preserved.
- 21 material families, 127 original PNG textures including source-packed Unity metallic/smoothness maps.
- 56 installable part records and **exactly one W075 jumper**; 18 supporting models.
- 74 unverified copper tasks, 16 unassigned-net via tasks, 3 fault definitions, 6 objectives.
- All source manifests are preserved under `Level98/Data/` alongside separately generated `L98_AutoGen_*.csv/json` normalized V2 manifests.

### Table sizing and model axes

- Source FR-4 PCB 180 mm X × 120 mm Y, 1.6 mm thick, GLB authored Z-up. Converted OBJ uses Unity X-right / Y-up / Z-depth, with `x,y,z -> x,z,-y` rotation.
- Uniform game visual scale: **10.13 × 6.7533 Unity units** measured by the physical FR-4 substrate, preserving 180:120 aspect ratio.
- Workshop tabletop: **15.79 × 8.54 units**. Nominal PCB margins: 2.83 units left/right, 0.8933 units front/back.
- The empty PCB source includes a decorative connector/silkscreen overhang to X=+100 mm (full visible X extents 190 mm rather than 180 mm). Do not fit by total mesh X bounds: board substrate must stay 10.13 wide. With overhang, total visible art reaches about 10.693 units wide and remains inside the tabletop.
- The workshop visual root is uniformly scaled, not the solver. Source electrical lengths, geometries, resistance, power and time are **not** modified by display scaling. Bind the real solver to source physical units.

### Installation

1. **Back up the Unity project** and close Unity.
2. Extract the full package ZIP **outside** the Unity project.
3. Open PowerShell in the extracted folder, then run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level98_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. The installer finds the one existing `SparkAutoLevelSourceImporter.cs` and updates that generator's Editor/Runtime scripts in place. It also **reuses an existing source folder** identified by `Model_Manifest_74.csv`, rather than duplicating the source. It preserves existing original models/textures by default and backs up any replaced scripts/normalization files under `ProjectSpark_Level98_Backups` outside Assets.
5. Reopen Unity 6.3, let imports finish, and clear all compiler errors.
6. Choose **Tools → Project Spark → Automatic Level Generator → 98 → 1. Build FULL Level_98_Layout**.
7. Select the real tabletop `Table_top` in the Hierarchy, then **98 → 2. Place Level 98 on SELECTED tabletop**. If Table_top is Transform-only, confirm its world Y is the **surface** height, not the table center.
8. Inspect top-down and profile views, URP material slots and color/normal maps; check `L98_Layout_Validation.txt`.

### Gameplay state and blockers

- Play starts **0/56 installables, 0/74 routes, 0/16 vias, 0/6 objectives**, W075 disconnected.
- The complete board visual is an inactive, non-scoring reference. It cannot make components installed, copper connected, W075 closed or objectives complete.
- Original copper CSV has `source_pad=UNASSIGNED`, `destination_pad=UNASSIGNED`, `electrical_verified=NO - MUST DESIGN NETLIST` on **all 74** routes; all 16 vias have `net_name=UNASSIGNED`.
- W075 logical feedback source and destination are documented but their physical pins are not verified. W075 carries trusted rail-valid feedback, **not** the 1.8 V power rail, load current or Kelvin sensing.
- Three faults: A elevated polymer capacitor ESR; B open ground return via; C Kelvin sense defect. Exact affected components/vias/traces must be assigned only from approved design data.
- To make this level playable, bind **actual Project Spark APIs** for placement, copper/via, electrical/thermal/transient solver, repair, measurements, save/load and `LevelGamePlayManager`. Do not invent project methods or awards.

### Troubleshooting

**`Recipe not found`**: confirm the installer placed `Level98_PIS6.recipe.json` into your existing generator's `Recipes` folder; the V2 window should find it after Refresh/Rescan Assets.

**`Missing CSV`**: confirm the source folder selected by the installer has the normalized files in `Data/` and is the same folder referenced by the recipe. The V2 importer auto-detects relocated sources if there is exactly one matching manifest.

**`Imported empty PCB has no measurable Renderer`**: confirm `Models_OBJ_Fallback/57_L98_PIS6_Empty_FourLayer_PCB.obj` is imported and has child MeshFilter + MeshRenderer objects. Our builder deliberately prefers that OBJ to the older custom-export FBX.

**Board is incorrectly sized**: don't fit total visible mesh X, because the connector decal adds 10 mm beyond the 180 mm FR-4 edge. Source scene must be Y-up XZ and board depth must import near 0.12 source units (modulo OBJ import scale).

**Default materials / textures are flat**: see the generated `URP_PBR_Materials/` folder, confirm the OBJ Material names, and check that normals are imported as Normal Maps and metallic/smoothness/occlusion data as linear textures. OBJ UVs are generated planar approximations because the GLBs do not provide usable TEXCOORD_0 in the inspected exporter data. Hand-authored UVs and custom texture bakes still needed for final AAA visual polish.
