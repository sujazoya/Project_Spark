# Project Spark — Level 101 THE HIDDEN LAYERS / MLX-9

## Scope
**AAA-style visual art and Unity Editor level-authoring upgrade only.** This does not claim a working six-layer electrical simulator, actual click-to-solder gameplay, complete repair mechanics, compiled Unity gameplay, or 6/6 objectives. It never invents electrical pins or pin-verified netlist assignments.

### Source preservation
Original source ZIP: `ProjectSpark_Level101_HiddenLayers_Realistic_BoardOnly_Complete.zip`.
The complete package retains all 96 FBXs, 96 GLBs, one assembled FBX/GLB showcase, 61 textures (12 source families x 5 maps + one silkscreen), the eight original Data records and both original art-only Unity editor scripts. These assets are not rewritten.

### Added assets
- 97 actual GLB-mesh-derived Unity Y-up OBJ+MTL fallbacks at **metre scale**; preserves original per-mesh material names and GLB UV coordinates (not generic replacement boxes).
- 12 URP metallic(R)+smoothness(A) textures derived from the original metallic and roughness PNGs; original AO and normal maps remain available.
- Editor PBR binder creates 12 idempotent Lit materials and remaps imported mesh material slots using preserved `__PSMAT__<family>` object markers.
- Full-layout builder with empty physical board, source structural pads and silk, 76 uninstalled footprint anchors, inventory visual prefabs, 100 blocked copper tasks and 24 blocked vias.
- Separate completed-board *visual-only* enlarged `Table_top` showcase with colliders stripped; this is not the gameplay prefab.
- Blueprint asset, Unity scene/prefab, validation report, source-to-visual maps, W101 conflict report, 96-test matrix marked NOT_RUN.

## Install / update
1. Close Unity. Back up the project. Extract **complete package** outside your Unity project. Keep folders `SourceAssets`, `Models_OBJ_Fallback`, `URP_Packed`, `GeneratorUpgrade` beside the PowerShell installer.
2. Open Windows PowerShell **in the extracted directory** and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level101_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

3. Open Unity 6.3 with URP; allow full mesh/texture/C# imports.
4. `Tools > Project Spark > Automatic Level Generator > 101 > 3. Validate Source and 3D Models`
5. `Tools > Project Spark > Automatic Level Generator > 101 > 1. Build FULL Level_101_Layout`
6. For a separate **completed-board art preview only**, select `Table_top` in the Hierarchy; run `101 > 2. Place Level 101 on SELECTED tabletop`. Do **not** use this preview as playable GameObject.
7. Optional: `101 > 4. Rebuild URP PBR Materials`.

The separate `Tools > Project Spark > Levels > Create Level 101` menu invokes the same full-layout builder. The original art-only editor menus are left untouched.

### Board scale
Physical PCB = 0.230 X x 0.160 Z metres. Preview uses a separate uniform art scale = 10.13 / 0.230 ~= 44.0435. Visual size 10.13 x 7.047 Unity units; fits the target table 15.79 x 8.54, leaving ~2.83 units left/right and ~0.75 units front/back. No art scale is fed into circuit calculations.

### W101 / schematic STOP GATES
**Conflict:** source safety contract names monitor U10 and supervisor U11, but the BOM says U7 LINK_MON, U8 SAFETY, U10 LDO, U11 INTERFACE. This is NOT reconciled. Exact W101 pins and all 100 route nets / 24 via net and layer spans remain unapproved. Their source records are preserved without modification. The builder creates no functional terminal connections for them and will not mark six objectives complete. See `GeneratorUpgrade/Docs/L101_W101_SafetyReconciliation_REQUIRED.md`.

### Unity verification
Offline asset geometry, naming, manifest and ZIP-CRC checks are performed. No Unity Editor executable is available in this environment. C# compile, renderer material appearance, tool integration, electrical graph, Play Mode and regressions for Levels 1–100 are **NOT_RUN / NOT_VERIFIED**. Visual meshes are procedural source assets; not manufacturer-certified or artist-finished AAA bakes.

The Level101-specific scripts do not replace `LevelGamePlayManager`, `SparkTerminal`, existing universal generator V2 classes or prior level scripts. They create authoring metadata only.
