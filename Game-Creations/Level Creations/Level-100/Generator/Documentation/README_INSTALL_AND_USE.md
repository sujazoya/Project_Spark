# Project Spark Level 100 Digital Nexus (DNX-8) — Full Auto Layout Upgrade

## Contents
Full ZIP preserves the original 88 modular FBX/GLB pairs, 70 uninstalled component models, 18 board-only structural models, assembled showcase FBX/GLB, 127 PBR source PNGs, and verbatim original planning data. Unity-native OBJ fallbacks (89 OBJ+MTL) are included. GLB-to-OBJ conversion preserves material names and uses Y-up Unity XZ board, with fallback planar UVs where source UV are absent.

## Install (Windows / Unity 6.3 URP)
1. Back up your project and close Unity.
2. Extract the ZIP into a new folder OUTSIDE `Assets`.
3. In PowerShell while inside the extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level100_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Open Unity. Wait for all mesh and shader imports; ensure Console has no compile errors.
5. `Tools > Project Spark > Automatic Level Generator > 100 > 1. Build FULL Level_100_Layout`.
6. Select the scene's `Table_top` GameObject, then choose `100 > 2. Place Level 100 on SELECTED tabletop`.
7. Inspect the `Level_100_Layout.prefab` visually and verify all shared model materials; adjust light/reflection probes with your existing room.

## Tabletop
Table: 15.79 X by 8.54 Z Unity units; PCB visual footprint 10.13 X by 6.9945 Z, preserving 210:145 board aspect ratio. Margins: 2.83 left/right, approx 0.773 front/back. `Table_top` without a Renderer/Collider is accepted as a surface-height anchor; verify its Y. The source board is 0.210 x 0.145 metres in physical gameplay, distinct from art enlargement.

## Gameplay & certification boundary
This is art/full-layout scaffolding; not a working I2C/SPI/UART simulator. All 92 route endpoint tuples, 20 vias and W093's physical pins remain unverified. Do not treat reference art, collider hits, empty placement targets or visual status records as installed electrical connections. The existing Project Spark gameplay code must be connected to approved netlists to certify 6/6. The separate assembled board is disabled and reference-only.

## Upgrade-only ZIP
Only use if the original Level 100 source kit is already installed in `Assets` (FBXs, GLBs, textures, Data). The installer expects exactly one existing Universal Automatic Level Generator V2 and updates it in-place; never creates a duplicate generator. Copies original source files only when absent by default. Replaces generator scripts with backups; generated layouts are not overwritten until you explicitly confirm regeneration.

## Validation limitations
Offline ZIP integrity and normalized-data checks are not Unity compilation, Unity import, Play Mode, renderer or game-solver verification. Unity may vary for custom FBX imports. Generated OBJ UVs are planar fallbacks not hand-baked AAA assets. Visually inspect materials and precision solder joints in Unity.
