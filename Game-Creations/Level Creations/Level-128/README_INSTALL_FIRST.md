# Project Spark Level 128 — The AORUS Master

## What is included
- 710 modular binary FBX files, plus 2 assembled binary FBX files (FBX 7.4, with geometry, normals, UVs, hierarchy and material slots).
- `L128_CompleteMotherboard.fbx`: editable hierarchy; 699 assembled groups (PCB + 682 factory parts + 16 removable parts), 138,036 triangles, 1,425 renderer mesh groups.
- `L128_CompleteMotherboard_Batched.fbx`: same triangle geometry, 15 grouped material meshes. Prefer for visual showcases. Not a removable-part gameplay hierarchy.
- `L128_CompleteMotherboard.glb`: independently readable backup with PBR factors; textures are separate.
- 16 procedural material families: 48 PNG maps at 2048×2048. BaseColor=sRGB, Normal=normal map, MetallicSmoothness=linear, metal in R and smoothness in A. FBX does not embed these textures; the Unity tool assigns them. GLB is factor-only, maps supplied separately.
- 8 schematic-unassigned layer overlays and 3 optional CPU / DDR5 / SSD service models. Original art, based on public dimensions and product features. Not the official CAD, BOM, physical pinout, schematics, or manufacturing files. Mounting-hole locations, small components, and internal package/connector geometry are approximations. No manufacturer affiliation implied.

## Install in Windows PowerShell 5.1
Back up and close Unity. Extract the FULL ZIP outside Assets. Find the directory containing `Install_Level128_AAA_AutoLayout.ps1`, `SHA256SUMS.csv`, and `Assets`. In PowerShell run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level128_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark" -DryRun
powershell -ExecutionPolicy Bypass -File ".\Install_Level128_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```
The dry run validates hashes and reports proposed changes. It does not create folders or write files. Existing differing files are refused. Use `-ReplaceExisting` only for a deliberate replacement of this level's package files; originals are backed up in `Level128_InstallerBackups` outside Assets. Existing Unity .meta files are never copied or removed. Levels 1–127 are untouched. Windows execution is not tested in this environment.

## Unity authoring
Use `Tools > Project Spark > Automatic Level Generator > 128`.
1. `3. Validate Sources and Report Blockers`. Requires all 710 modular and both assembled FBX imports to have meshes. Validates PCB X=.244m and Z=.305m; refuses if importer axes/scale are wrong. If importer settings were compiled after initial import, reimport the Models_FBX folder and inspect the Console.
2. `4. Rebuild URP PBR Materials`. Creates 16 native URP Lit materials, with explicit texture rules.
3. `5. Create COMPLETE assembled motherboard (VISUAL ONLY)` for the editable hierarchy.
4. `6. Create BATCHED motherboard (VISUAL ONLY)` for the reduced-renderer showcase.
5. `1. Build FULL Level_128_Layout` creates a separate service authoring scene. Factory board components and removable mechanical objects are present; optional CPU/RAM/NVMe service targets are empty. Layer overlays are inactive. This differs from previous blank PCB assembly levels deliberately: a PC motherboard repair level starts with a factory board.
6. Select Table_top and use `2. Place assembled VISUAL preview on SELECTED tabletop`. This rotates the board and applies a uniform presentation scale to fit the selected bounds; it is not the physical electrical model.

Generated outputs under `Assets/ProjectSpark/AutoGeneratedLevels/Level128/`:
- `L128_CompleteMotherboard_VISUAL_ONLY.prefab`
- `L128_CompleteMotherboard_Batched_VISUAL_ONLY.prefab`
- `Level_128_Layout.prefab` and `Level_128_Layout.unity`
- `URP_PBR_Materials/`

Physical coordinates: mm in FBX, unit scale 0.1 cm/mm, Y-up, top of PCB at y=0. Width along X 244mm, length along Z 305mm. Manifest positions are metres. FBX import and C# compile must be verified locally; see OfflineValidation.json for the actual independent binary structural audit. No fake Unity import or AAA certification is claimed. GLB is a geometry fallback if a particular FBX importer rejects the custom exporter. If publishing the game, consider permissions and branding review.
