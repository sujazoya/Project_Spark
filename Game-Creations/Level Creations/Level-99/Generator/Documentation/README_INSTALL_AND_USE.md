# Level 99 — Silicon Brain SBC-7: Realistic PBR Full Auto-Layout Upgrade

This additive Level 99 pack upgrades the **existing** Project Spark Universal Automatic Level Generator V2 for Unity 6.3 / URP. It produces source-backed 3D visual layouts and gameplay integration scaffolding, **not** independently proven electrical/firmware gameplay. Unity compilation and Play Mode are not tested by offline packaging.

## One-time installation

1. Back up `D:\Project_Spark_Master_Project\Project_Spark`, close Unity and extract the **full** ZIP outside the Unity project.
2. Open PowerShell in the extracted root and run:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level99_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

3. The installer discovers the one existing `SparkAutoLevelSourceImporter.cs` and installs new Level 99 scripts into **that same** generator. Do not create a second V2 generator folder. Source FBX, GLB and texture files are preserved by default; replacements are backed up.
4. Reopen Unity and let FBX/OBJ imports and C# compilation finish.
5. Select **Tools → Project Spark → Automatic Level Generator → 99 → 1. Build FULL Level_99_Layout** (also **Tools → Project Spark → Levels → Create Level 99**).
6. Select `Table_top` in Hierarchy and choose **99 → 2. Place Level 99 on SELECTED tabletop**. When your `Table_top` has only a Transform, confirm that its Y position actually represents the **upper surface center**. The anchor's scale will **not** be inherited.

## Models and realistic PBR materials

The original 80 FBX + 80 GLB modular models, assembled FBX/GLB reference and 127 PNG textures are preserved in the full package. 81 generated `.obj`/`.mtl` fallbacks use geometry extracted from the GLBs, rotated from their Z-up format to Unity Y-up and grouped by original material names. Source GLBs lack UVs; provisional planar UVs are generated for OBJ. The 21 URP/Lit materials use original albedo, metallic/smoothness, normal and AO maps. Verify texture appearance, UV mapping, normals and FBX/OBJ overrides at high zoom; these are realistic-style source assets, not bespoke AAA-certified manufactured CAD meshes.

The 62 component meshes remain individually addressable and uninstalled. The fully assembled reference is **disabled** in the generated gameplay hierarchy. No new room, furniture, physical instrument models or unrelated scenery is included.

## Electrical blockers

All 82 route endpoints have `SCHEMATIC_REQUIRED` contacts and unassigned nets; 18 via plans have unassigned nets, positions and layer spans. W083 is a conceptual heartbeat link `U1.APPLICATION_HEARTBEAT_OUT → U8.TRUSTED_HEARTBEAT_IN`, not a verified physical pin map. The builder does **not** confer circuit connectivity or six gameplay objectives.

The exported hierarchy includes placeholders for existing solver, placement/solder, traces/vias, firmware, SWD, peripheral diagnostics, faults and World-Space Canvas virtual tools. A real `LevelGamePlayManager` integration needs project source API inspection and a reviewed schematic. See `CODEX_PROJECT_BINDING_TASK_L99.md`.

## Safety of upgrades

The installer updates only Level 99 source assets and its uniquely named Level 99 extension classes under the installed generator, with backups for replaced files. It does not overwrite Level 1–98 assets or auto-regenerate existing scenes. Regenerating an existing `Level_99_Layout` needs an explicit confirmation. Preserve manual changes in prefab variants.
