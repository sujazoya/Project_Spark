# Project Spark — Level 102 SIGNAL PHANTOM (HSX-10)
## Complete AAA-style Visual-Layout Upgrade — Unity 6.3 / URP

This is an **upgrade for the existing Project Spark project**, not a new room or a certified gameplay implementation. It preserves original FBX/GLB geometry and the 90 original reference PBR maps; it adds 105 UV-reconstructed OBJ fallbacks, 18 URP mask textures, 18 URP occlusion textures, Level 102 source-data/visual prefab tools and a non-destructive installer.

### Install on Windows

1. Back up your Unity project and close Unity.
2. Extract the complete ZIP to any folder outside your Unity project. Do not directly drag the entire ZIP into Assets.
3. Run from that extracted folder:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level102_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

4. Reopen Unity. Wait for compilation and texture import. Check the Console.
5. Use `Tools > Project Spark > Automatic Level Generator > 102 > 3. Validate Imported Art and Source`.
6. Use `Tools > Project Spark > Automatic Level Generator > 102 > 1. Build FULL Level_102_Layout`.
7. Select your Transform-only `Table_top` anchor in the hierarchy. Use `102 > 2. Place Level 102 on SELECTED tabletop`.

An alias `Tools > Project Spark > Levels > Create Level 102` builds the same **source-only** full layout. The old source `102/1. Build EMPTY` menu forwards to the upgraded layout builder. It does **not** award objectives.

- A separate enlarged **visual-only** tabletop preview: **10.13 x 7.091 Unity units** on the 15.79 x 8.54-unit workshop tabletop. This preview has no gameplay/physics claims.

### Realistic materials

The material builder uses all 18 original PBR material families from `Textures/`, generated URP metallic-in-red + smoothness-in-alpha masks and green-channel ambient-occlusion maps, as well as the original normal maps. It prefers original FBX geometry when Unity actually imports renderable meshes and falls back to the matching OBJ if not. OBJ UVs are procedurally reconstructed with planar per-face projection because the GLB sources do not contain UVs. Review seam alignment, model import sizes and metallic masks in Unity; artist-authored bakes and manufacturer-grade CAD are not supplied.

### Preserving existing work

Installer discovers existing Level 102 data roots, does not overwrite original FBX/GLB/textures/data, and puts backups of replaced Level 102 C# scripts outside `Assets` under `ProjectSpark_Level102_UpgradeBackups/`. It refuses ambiguous duplicate source data roots. Generated prefabs require an explicit Unity Editor action and confirmation before replacing an existing prefab. Other levels are not modified.
