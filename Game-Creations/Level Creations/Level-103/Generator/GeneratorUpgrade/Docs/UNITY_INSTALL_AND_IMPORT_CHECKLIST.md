# Level 103 — Complete Upgrade Installation / AAA Visual Inspection

1. **Back up the Unity project and close Unity**. Extract full ZIP to a folder **outside** `Assets`.
2. In PowerShell opened in the extracted ZIP folder, execute:

   `powershell -ExecutionPolicy Bypass -File ".\Install_Level103_AAA_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"`

3. Reopen Unity 6.3 URP, wait for ModelImporter and C# compilation. Original FBX has centimetre geometry while GLB-derived OBJ is in metres. The new builder **always uses the OBJ meshes**. Do not compensate importer global scale twice.
4. Use **Tools > Project Spark > Automatic Level Generator > 103 > 3. Validate Source and 3D Models**. Expected 112 modular source pairs + 113 renderable OBJ meshes.
5. Use **103 > 1. Build FULL Level_103_Layout**. Generates `Assets/ProjectSpark/AutoGeneratedLevels/Level103/Level_103_Layout.prefab`, `.unity`, `L103_SourceBlueprint.asset`, `L103_Layout_Validation.txt`, 88 art inventory prefabs and 23 URP materials.
6. Verify physical PCB `Renderer.bounds` X=0.240m, Z=0.180m, no auto-installed parts, all route/via markers uncertifiable, showcase disabled. Inspect material names, normals, UVs and shaders for source limitations.
7. Select **`Table_top`** Transform in your existing workshop (15.79x8.54 units), then choose **103 > 2. Place Level 103 on SELECTED tabletop**. The assembled reference is a **VISUAL-ONLY** preview about **10.013 × 7.51 units**, enlarged uniformly. No colliders, solver, gameplay, route mutations or completion.
8. Optional **103 > 4. Rebuild URP PBR Materials**. The original source texture files remain in place.

### Important limitations

Visual geometry and generated prefab references alone **do not** satisfy installation, continuity, VRM power, thermal repair or any of six objectives. Only a later reviewed netlist and actual existing Project Spark runtime authority can achieve that. Compilation and Play Mode were not tested in the packaging sandbox; inspect Unity Console and copy any error lines to update the code.
