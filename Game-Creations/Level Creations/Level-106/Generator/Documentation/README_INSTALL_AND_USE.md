# Project Spark — Level 106 First Boot (SFX-14) Full Auto Layout Addon

This is an addon for the already installed **Universal AutoLevelGenerator V2**. It does not install another copy of the generator, modify Levels 1–105, or complete electrical gameplay.

## Installation (your Unity project)

Unity root: `D:\Project_Spark_Master_Project\Project_Spark`

1. Back up the Unity project and **close Unity**.
2. Extract the **FULL** package (if Level 106 source assets are not yet imported); otherwise the **UPGRADE ONLY** package can reuse your existing original Level 106 source kit.
3. Open PowerShell in the extracted folder containing `Install_Level106_AutoLayout.ps1`.
4. Execute:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Install_Level106_AutoLayout.ps1" -UnityProjectPath "D:\Project_Spark_Master_Project\Project_Spark"
```

5. Open Unity. Let **both FBX and OBJ** finish importing and the C# domain reload complete.
6. Generate the **full hierarchy**, not only the V2 empty-board scaffold:

`Tools > Project Spark > Automatic Level Generator > 106 > 1. Build FULL Level_106_Layout`

7. Confirm the output under `Assets/ProjectSpark/AutoGeneratedLevels/Level106/`:

- `Level_106_Layout.prefab`
- `Level_106_Layout.unity`
- `L106_SourceBlueprint.asset`
- `L106_Layout_Validation.txt`
- `URP_PBR_Materials/`

8. In the workshop scene, select the **scene** `Table_top` object in Hierarchy, then:

`Tools > Project Spark > Automatic Level Generator > 106 > 2. Place Level 106 on SELECTED tabletop`

For a Transform-only `Table_top`, the placer asks you to confirm that its **position** is the tabletop *surface center*. It ignores `Table_top.transform.localScale`; do not alter the tabletop mesh scale to match the board.

## Workshop scale / fit

- Tabletop: **15.79 × 8.54 Unity units**.
- Motherboard: **10.13 × 7.51 Unity units**.
- Centered margins: **2.83** units left/right; **0.515** units front/back.
- Original source board: **285 × 205 × 1.6 mm**, geometry is **Z-up in meters**. The builder rotates it to Unity Y-up when required and fits the imported *rendered mesh* bounds, not arbitrary Transform scale.

## Renderable model fallback

The package retains the original 136 FBX/136 GLB files and assembled reference FBX/GLB, **plus 137 OBJ fallback meshes** derived from the GLBs. The builder checks if a model has actual mesh geometry and prefers the OBJ fallback if available. This prevents the "Imported empty PCB has no measurable Renderer" error observed with some procedural FBX exports. The OBJ geometry has been grouped by source material family to reduce imported object count; Unity import and URP PBR material assignments still require real visual QA.

## Layout / protection

- 106 **uninstalled** component targets, with placeholder collider footprints and asset references.
- 140 **unrouted** copper tasks (NOT_CERTIFIABLE).
- 42 **unassigned** vias (NOT_CERTIFIABLE).
- 10 copper layer visualization references.
- 3 source-backed fault definitions, 6 objective placeholders.
- W141 independent safety placeholders; physical pin mapping not supplied.
- First Boot systems and virtual tool binding anchors, **not new working scripts** for CPU/DDR4/firmware/PCIe/eMMC.
- Completed reference board is **disabled by default**; it does not count as installed components.

**The source-level U14 SystemBootMonitor is absent from the component BOM**. The builder reports this as an unresolved safety prerequisite, not as a guessed physical component. The project electrical graph and `LevelGamePlayManager` remain authoritative; route/repair/POST data must not be fabricated.

## Non-destructive upgrade

Installer discovers the single existing generator core under Assets, detects duplicate addon scripts, backs up scripts/recipe files it overwrites, and leaves generated scenes and earlier levels untouched. Running the builder a second time requests permission before replacing *generated* Level 106 scene/prefab. Keep manual gameplay edits in separate prefabs.

## Troubleshooting

- **Recipe not found**: rescan, confirm `Level106_SFX14.recipe.json` in your existing generator `Recipes` directory. The Level 106 dedicated menu finds the recipe by name.
- **No measurable Renderer**: confirm `Assets/ProjectSpark/Level106/Models_OBJ_Fallback/107_L106_SFX14_BarePCB.obj` exists, has a mesh in Unity preview, and the OBJ importer finishes without errors. The addon prioritizes renderable OBJ models.
- **No tabletop bounds**: `Table_top` may be a Transform-only anchor. Select it in Hierarchy (not Project) and confirm its Y world coordinate is the actual tabletop **surface** height.
- **Missing safety/route source**: rerun installer; use `L106_AutoGen_*.csv/json` files; they preserve all explicit UNASSIGNED statuses.
- **C# duplicate class errors**: don't install a second Universal Generator V2 copy or duplicate Level106 builder file. The script installer will refuse if duplicates are found.

**Offline package checks do not prove Unity compilation or Play Mode success.** Import and inspect in Unity before accepting the level.
