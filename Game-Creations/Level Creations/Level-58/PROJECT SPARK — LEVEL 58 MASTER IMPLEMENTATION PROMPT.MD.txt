# 8. INVERSE-TIME OVERCURRENT PROTECTION

Implement a simplified, configurable inverse-time relay characteristic.

For an IEC standard-inverse example:

`t = (0.14 * TMS) / ((I / Is)^0.02 - 1)`

Where:

- `t` = trip time in seconds
- `TMS` = time multiplier setting
- `I` = measured current
- `Is` = pickup current

Apply this relationship only when current exceeds pickup and the selected curve supports it.

## Numerical requirements

- Do not evaluate the inverse-time expression at or below pickup.
- Clamp or handle extreme values safely.
- Avoid division by zero.
- Support reset or decay of accumulated relay operation according to the chosen model.
- Use simulation time, not frame count.
- Account for changing current during the fault.
- Separate relay trip-request time from breaker mechanical opening time.

## Required player controls

- PICKUP CURRENT
- TIME MULTIPLIER
- CURVE TYPE
- INSTANTANEOUS SETTING
- ARM RELAY
- RESET RELAY
- VERIFY COORDINATION

The player must understand that a lower pickup setting is not always the correct solution.

The protection must avoid nuisance trips while clearing genuine faults promptly.
