# Review and approval

A draft can be shown in Spark Live with `spark preview construction`. The preview reports the currently loaded layout, recorded candidate pairs, and live terminal resolution. The existing Editor review path accepts a generated draft only when it matches the active authored recipe. A separate explicit authorization binds the reviewed revision before Auto Draw can execute it.

Review every required step, including placement, power-off sequencing, tool contracts, and evaluator objectives, against the actual level evidence. A structural draft or a temporary Play Mode fixture does not authorize an asset for player execution.
