# Native construction plan workflow

Use the Unity menu under Project Spark → SUPER AI → Universal Auto Draw to scan, export, generate drafts, review a selected native plan, and bind an approved review to the current authored revision.

The Level 20 source is the existing reviewed ten-wire plan, backed by the schematic reference level-20-complete-wiring. A second Level 20 asset has no reviewer or approval. The exported draft is a JSON candidate with a companion evidence file. The draft cannot run from the report folder.

For a new layout, record the native terminal pairs or obtain equivalent authoritative authored instructions. Review the ordered pairs, schematic evidence, component ownership, and runtime-slot prerequisites. Use the existing native plan approval workflow, then select Approve Selected Reviewed Revision to bind the reviewed requirements to the definition and prefab. An edited definition, nested prefab, or approved pair list requires review again.

The wiring flow can verify a runtime slot after the player uses the native shelf to install its component. Board placement records, artwork, and unverified copper or via tasks do not provide executable tool actions on their own.

## Other authored sources inspected

Levels 96 and 97 include resolved educational PCB pad or pin netlists. Their pad records and net membership are useful board evidence. The existing generic Wire Tool requires native layout terminal owner bindings and reviewed ordered actions for this board workflow. The netlists were not translated into cable connections. Level 124 has authored placement and blocked task records that expose unverified footprints and no bound integration authority.
