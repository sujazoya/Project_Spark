# SUPER AI v19 architecture

Spark Live routes the exact draw command and its aliases through SparkProExecutive to the existing engineering control hub. The hub honors the current Manual, Assisted, Auto, or independent exam state. The command never changes the selected mode.

The level manager provides the active definition, evaluator, and circuit. The catalog and loader provide the actual authored prefab identity. The wiring plan binds its existing reviewer, schematic reference, ordered native terminal pairs, and approval digest to the exact definition and a content revision of the authored prefab and nested prefabs. The Editor revalidates the source revision before a player build.

The hub resolves live terminal IDs through the layout's own bindings and checks existing connectivity through SparkCircuitSystem. Unpopulated runtime slots block their dependent steps. The existing Native Wire Director, cinematic, telescopic hands, and player Wire Tool handle the physical operations. The hub counts a connection after the authoritative circuit registers it. The level manager owns completion and failure.

The existing Engineering Control overlay shows the active level, mode, progress, current action, manipulation stage, and controls. Existing Spark Live narration and Android speech adapters serve the same command path. Campaign and draft tools are Editor-only.
